# Анализ контестов

## Что такое анализ контестов?

Анализ контестов - это разбор участия в контестах Codeforces с выявлением паттернов ошибок и рекомендациями для улучшения.

**Цель анализа:**
- Понять почему задачи не получились
- Выявить слабые темы и стратегические ошибки
- Получить конкретные рекомендации
- Зафиксировать прогресс и паттерны

## Поддерживаемые типы

### Solo (индивидуальный)

Анализ твоего личного участия в контесте.

### Team (командный)

Анализ участия команды (2-3 человека) в контесте.

**Отличия team от solo:**
- Анализ вклада каждого участника
- Выявление дублирования усилий
- Оценка эффективности команды
- Рекомендации по координации

## Как запустить?

### Через интерактивное меню

```
/coach
```

Выбери пункт **4. CONTEST** из меню.

### Прямая команда

```bash
/coach contest
```

## Подготовка: Заполнение CONTEST.md

Перед запуском анализа нужно заполнить `solution/CONTEST.md`.

### Формат файла

```markdown
# Ссылка на контест
https://codeforces.com/contest/1234

---

# Тип контеста
solo

---

# Команда

## Ваш handle
tourist

## Участники команды (только для team)

```

### Поля

**Ссылка на контест:**
- URL контеста на Codeforces
- Пример: `https://codeforces.com/contest/1234`

**Тип контеста:**
- `solo` - индивидуальный
- `team` - командный

**Ваш handle:**
- Основной handle пользователя (из профиля)

**Участники команды:**
- Только для team режима
- Handles других участников, каждый с новой строки
- Пример:
  ```
  Petr
  vepifanov
  ```

## Частые вопросы

### Как часто анализировать контесты?

**Рекомендуется:** После каждого контеста.

**Минимум:** Раз в 2-3 контеста.

**Идеально:** Сразу после контеста, пока помнишь детали.

### Что если не помню почему задача не получилась?

**Не проблема.** Напиши что помнишь:
```
> Не помню точно, но помню что застрял на DP
```

Тренер проанализирует теги, время, попытки и сделает выводы.

### Можно ли анализировать старые контесты?

**Да!** Codeforces API хранит историю.

Вставь ссылку на любой контест где участвовал.

### Что если участвовал в team, но не все участники есть в профиле?

**Не проблема.** Укажи handles в CONTEST.md.

Анализ будет работать для всей команды, но связь с профилями только для тех, кто есть в системе.

### Нужно ли дорешивать задачи после анализа?

**Настоятельно рекомендуется!**

После анализа:
1. Вставь разбор нерешённой задачи в solution/PROBLEM.md
2. Изучи решение
3. Создай детальный editorial
4. Повтори тему (/coach → обучение)
5. Решить 2-3 похожие задачи

### Влияет ли анализ контеста на confidence?

**Нет напрямую.**

Но выявленные слабости:
- Подтверждают оценку confidence
- Могут добавить новые weak_topics
- Влияют на план тренировок

Для роста confidence:
- Изучи слабую тему (обучение)
- Решить задачи (практика)
