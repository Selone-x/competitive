## 💡 Философия системы

> **Олимпиадное программирование - это не про знание алгоритмов, а про умение мыслить.**

Поэтому Claude Coach фокусируется на:
- ✅ Анализе **процесса мышления**, а не только кода
- ✅ Выявлении **ошибок в логике**, а не только багов
- ✅ Формулировке **критических вопросов**, которые нужно было задать
- ✅ Поиске **паттернов** задач, а не зубрежке решений
- ✅ **Персональном плане** на основе ваших слабых мест
