# Обзор системы Claude Coach

## Что это такое?

**Claude Coach** - это персональный тренер по спортивному программированию, работающий на базе Claude Code CLI.

Это **не просто ассистент для решения задач**, а полноценная система обучения, которая:
- 🎓 **Анализирует ваши слабые места** на основе статистики Codeforces
- 📊 **Создает персональный план тренировок** под ваш уровень и цели
- 🧠 **Фокусируется на процессе мышления**, а не только на коде
- 📚 **Помогает изучать новые темы** в структурированном формате
- 💪 **Тренирует мышечную память** через drill (набивашки)
- 🔍 **Анализирует участие в контестах** и выявляет паттерны ошибок

## Зачем это нужно?

### Проблемы традиционного подхода

**Традиционно** при подготовке к олимпиадам:
- ❌ Решаешь задачи вслепую, без понимания слабых мест
- ❌ Застреваешь на задаче → смотришь разбор → понимаешь решение, но **не понимаешь почему не додумался сам**
- ❌ Изучаешь алгоритм → забываешь детали через неделю
- ❌ Набиваешь код медленно даже на знакомых темах
- ❌ После контеста не анализируешь ошибки системно

### Как решает Claude Coach

**С Claude Coach:**
- ✅ **Персональный анализ** - система знает твои слабые темы на основе CF статистики и самооценки
- ✅ **Фокус на мышлении** - при разборе задачи акцент на "почему не додумался", а не "вот код"
- ✅ **Структурированные материалы** - формат Zettelkasten для изучения тем с связями между концепциями
- ✅ **Drill (набивашки)** - тренировка мышечной памяти для быстрого набивания кода
- ✅ **Анализ контестов** - выявление паттернов ошибок и стратегических проблем
- ✅ **Отслеживание прогресса** - видишь как растет уровень по каждой теме

## Ключевые компоненты

### 1. Персональный тренер `/coach`

Главная фича системы - интерактивный тренер с 8 режимами:

**Основные режимы:**
1. **📚 Обучение** - изучение слабых тем с quiz и практикой
2. **💻 Практика** - решение задач с консультацией тренера
3. **🔨 Drill** - набивание кода по памяти для тренировки рук
4. **📊 Contest** - анализ участия в контестах (solo/team)

**Статистика и настройки:**
5. **📈 Stats** - просмотр прогресса и статистики
6. **📅 Plan** - текущий план тренировок
7. **🔄 Sync** - синхронизация с Codeforces
8. **⚙️ Настройки** - управление профилем

### 2. Система разборов задач

**Формат разбора** фокусируется на процессе мышления:
- ✅ Что понял правильно
- ❌ Пропущенный шаг и ошибка в логике
- 💡 Критический вопрос, который не был задан
- 🎯 Признаки задач этого типа

**Файл:** `solution/PROBLEM.md` - два режима работы:
- Режим помощи (разбор пустой) - Claude консультирует, но не ведет за руку
- Режим объяснения (есть разбор) - Claude объясняет готовое решение

### 3. Библиотека алгоритмов

**Формат:** Код готовый к копированию в контесте
- **Копируемый блок** - чистый код без комментариев
- **Комментированная версия** - тот же код с объяснениями
- **Метаданные** - название, сложность, ключевые слова для поиска

**Папки:**
- `library/cpp/` - реализации на C++
- `library/py/` - реализации на Python

### 4. Изучение тем (Zettelkasten)

**Формат:** Атомарные заметки со связями
- Одна заметка = одна концепция
- Интуитивные объяснения с примерами
- Ссылки на связанные заметки
- Карта знаний (index.md) для навигации

**Папка:** `editorials/{topic}/`

### 5. Анализ контестов

**Функционал:**
- Загрузка результатов через Codeforces API
- Поддержка solo и team режимов
- Анализ стратегии и распределения времени
- Выявление паттернов ошибок
- Рекомендации для улучшения

**Файл:** `solution/CONTEST.md` - ссылка на контест и тип (solo/team)

## Как это работает?

### Цикл обучения

```
1. Инициализация
   ├─ Анализ CF профиля
   ├─ Оценка знаний (quiz)
   └─ Создание плана

2. Тренировка
   ├─ Обучение (слабые темы)
   │  ├─ Материалы (Zettelkasten)
   │  ├─ Quiz для проверки
   │  ├─ Практическая задача
   │  └─ Обновление confidence
   │
   ├─ Практика (решение задач)
   │  ├─ Рекомендация задачи
   │  ├─ Консультация при решении
   │  ├─ Разбор после AC
   │  └─ Обновление confidence
   │
   └─ Drill (набивашки)
      ├─ Показ метаданных (без кода)
      ├─ Набивание по памяти
      ├─ Семантическая проверка
      └─ Обратная связь

3. Анализ
   ├─ Статистика прогресса
   ├─ Синхронизация с CF
   └─ Анализ контестов

4. Повтор цикла
```

### Обновление уровня (confidence)

**Как растет confidence по темам:**
- После quiz в обучении: +1-2 (зависит от результата)
- После решения задачи: +1
- **Важно:** Рост постепенный - тема не станет сильной за одну сессию

**Цель:** Реалистичная оценка знаний, а не быстрое заполнение прогресса

### Персональный план

**План автоматически определяет:**
1. **Фазу подготовки** (fundamentals/intermediate/advanced/expert) - на основе рейтинга
2. **Приоритетные темы** - пересечение слабых тем и фокуса фазы
3. **Расписание** - сколько задач в неделю, баланс между обучением и практикой

**План адаптируется:** По мере роста confidence приоритеты смещаются на следующие слабые темы

## Отличия от обычного использования Claude

### Обычное использование Claude

```
Пользователь: Помоги решить задачу X
Claude: [Даёт решение]
Пользователь: Спасибо!
→ Пользователь получил решение, но не обязательно понял процесс
→ Нет отслеживания прогресса
→ Нет персонального плана
```

### Claude Coach

```
Пользователь: /coach → режим практики
Claude: Рекомендую задачу на DP (твоя слабая тема). Вот ссылка.
Пользователь: [Решает, задаёт вопросы только когда нужно]
Claude: [Отвечает на вопросы, но не подталкивает к решению]
Пользователь: Accepted!
Claude: Поздравляю! Ключевая идея: [разбор]. Confidence DP: 4→5
→ Пользователь решил сам с минимальной помощью
→ Прогресс зафиксирован
→ План обновлён
```

## Для кого эта система?

### Идеально подходит если ты:
- ✅ Готовишься к олимпиадам (Codeforces, AtCoder, ICPC)
- ✅ Хочешь системный подход к обучению
- ✅ Понимаешь, что важен не только код, но и процесс мышления
- ✅ Готов анализировать свои ошибки
- ✅ Хочешь видеть прогресс объективно

### Не подойдет если:
- ❌ Нужен только быстрый ответ на задачу (лучше обычный ChatGPT)
- ❌ Не готов проходить инициализацию и quiz
- ❌ Не интересует отслеживание прогресса

## Основные преимущества

### 1. Персонализация
- План тренировок под твой уровень
- Фокус на твоих слабых темах
- Учёт предпочтений (сбалансированный/фокус/челлендж)

### 2. Фокус на мышлении
- Не просто "вот решение", а "почему не додумался"
- Критические вопросы, которые нужно было задать
- Паттерны распознавания задач

### 3. Структурированность
- Материалы в формате Zettelkasten
- Библиотека готовая к копированию
- Единый формат разборов

### 4. Отслеживание прогресса
- Уровень по каждой теме (confidence 1-10)
- История сессий и задач
- Синхронизация с Codeforces

### 5. Практичность
- Drill для тренировки мышечной памяти
- Анализ контестов с рекомендациями
- Библиотека для быстрого копирования в контесте
