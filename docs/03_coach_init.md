# Инициализация профиля

## Когда запускается инициализация?

Инициализация профиля запускается автоматически в двух случаях:

1. **Первый запуск `/coach`** - когда файла `coach/core.json` не существует
2. **Явный вызов `/coach init`** - когда хочешь переинициализировать профиль

**Важно:** `/coach init` перезапишет существующий профиль!

## Цель инициализации

Создать персональный профиль, который включает:
- ✅ Анализ твоего уровня на Codeforces (опционально)
- ✅ Оценку знаний по 10 основным темам через quiz
- ✅ Персональный план тренировок под твои цели
- ✅ Настройки предпочтений

## Процесс инициализации

### Шаг 1: Приветствие и контекст

```
Привет! Я твой персональный тренер по спортивному программированию.

Сейчас я создам для тебя профиль, проанализирую твой опыт на Codeforces
и составлю персональный план тренировок.

Работал ли ты уже со мной (Claude) для решения задач по CP? (да/нет)
```

**Зачем этот вопрос?**
- Если **да** - тренер понимает что ты знаком с подходом (консультация, а не решение за тебя)
- Если **нет** - тренер объяснит принципы работы

**Что ответить:**
- Ответь честно - это влияет на ожидания и стиль общения

### Шаг 2: Библиотека алгоритмов

```
У тебя есть свои шаблоны алгоритмов (набивашки) где-либо?
Например, отсортированные по темам файлы с реализациями, которые ты
копируешь в решения.
```

**Если есть библиотека:**

```
Отлично! Скопируй их в library/:
- C++ файлы → library/cpp/
- Python файлы → library/py/

Формат не критичен — я разберусь. Если хочешь, могу подсказать как оформить.
Скопируй и напиши "готово".
```

**Действия:**
1. Скопируй свои файлы в соответствующие папки
2. Напиши "готово" тренеру

**Проверка:**
```bash
ls library/cpp 2>/dev/null | wc -l
ls library/py 2>/dev/null | wc -l
```

**Результат:**
```
Проверил:
- C++: 5 файлов
- Python: 0 файлов

Всё на месте, буду использовать в обучении.
```

**Если нет библиотеки:**

```
Ок, библиотека пустая. Ничего страшного — будем заполнять вместе по мере тренировок.
```

**Что это даёт:**
- Тренер будет использовать твои файлы в режиме drill
- При обучении тренер может дополнять библиотеку

### Шаг 3: Интеграция с Codeforces

```
Укажи свой никнейм (handle) на Codeforces:
(Если нет аккаунта, введи "none" - создам план без анализа статистики)
```

#### Если указал handle

**Что происходит:**
1. Запускается Python скрипт:
   ```bash
   python3 .claude/skills/competitive-coach/scripts/codeforces_api.py {handle}
   ```

2. Скрипт через CF API получает:
   - Рейтинг и ранг
   - Количество решённых задач
   - Теги часто решаемых задач
   - Теги редко решаемых задач

3. Показывается анализ:
   ```
   Твой профиль на Codeforces:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Рейтинг: 1456 (specialist)
   Решено задач: 247

   Часто решаешь:
   • implementation - 45%
   • greedy - 28%
   • dp - 22%
   • math - 18%
   • brute force - 15%

   Редко решаешь:
   • geometry - 2%
   • strings - 3%
   • flows - 0%
   • fft - 0%
   • trees - 4%

   Это поможет мне понять твои сильные и слабые стороны.
   ```

**Что это даёт:**
- Объективная картина твоих сильных/слабых тем
- Более точный план тренировок
- Возможность синхронизации (`/coach sync`)
- Анализ контестов (`/coach contest`)

#### Если указал "none"

```
Ок, работаем без статистики CF. Оценим знания вручную через quiz.
```

**Что теряешь:**
- Анализ CF статистики
- Синхронизацию
- Анализ контестов

**Что остаётся:**
- Оценка через quiz (следующий шаг)
- Все режимы тренера (обучение, практика, drill)
- План тренировок (на основе quiz)

#### Возможные ошибки

**Ошибка: "User not found"**
- Проверь handle на правильность
- Попробуй открыть `https://codeforces.com/profile/{твой_handle}` - страница должна существовать

**Ошибка: "API error"**
- CF API временно недоступен
- Попробуй позже или используй "none"

### Шаг 4: Адаптивная оценка знаний (Quiz)

```
Начинаем оценку знаний!
Это адаптивный quiz по 10 основным темам. Для каждой темы 2-3 вопроса
в зависимости от твоих ответов.

Тема 1/10: Binary Search
```

#### Темы для оценки

1. **Binary Search** - бинарный поиск, поиск по ответу
2. **Two Pointers** - два указателя, sliding window
3. **Sorting & Searching** - сортировки, стандартные алгоритмы
4. **Dynamic Programming** - динамическое программирование
5. **Graphs (DFS/BFS)** - графы, обходы
6. **Greedy** - жадные алгоритмы
7. **Number Theory** - теория чисел (НОД, простые числа, модульная арифметика)
8. **Data Structures** - структуры данных (стек, очередь, set, map, heap)
9. **Strings** - работа со строками, pattern matching
10. **Geometry** - вычислительная геометрия

#### Алгоритм оценки каждой темы

**Вопрос 1 (базовый):**
```
Что такое {topic}? Когда оно применяется?
```

**Оценка ответа:**
- **Не ответил / "не знаю"** → confidence = 1, переход к следующей теме
- **Ответил грубо / неполно** → confidence = 2-3, переход к следующей теме
- **Ответил уверенно и осмысленно** → продолжить к Вопросу 2

**Вопрос 2 (применение):**
```
В каких задачах / когда ты бы использовал {topic}?
Как распознать задачу на этот паттерн?
```

**Оценка ответа:**
- **Не ответил / не может привести примеры** → confidence = 3-4, конец темы
- **Ответил грубо / частично** → confidence = 4-5, конец темы
- **Ответил уверенно с примерами** → продолжить к Вопросу 3

**Вопрос 3 (сложный):**
```
{сложный вопрос для темы — edge case, типичная ошибка, нетривиальный случай}
```

**Оценка ответа:**
- **Не ответил / не может объяснить** → confidence = 5-6, конец темы
- **Ответил правильно** → confidence = 7-8, конец темы
- **Ответил развёрнуто с примерами** → confidence = 9-10, конец темы

#### Примеры вопросов

**Binary Search:**
- Q1: Что такое бинарный поиск и когда он работает?
- Q2: Когда применять поиск по ответу vs по массиву?
- Q3: Как обработать ситуацию когда нужна первая/последняя позиция элемента?

**Dynamic Programming:**
- Q1: Что такое динамическое программирование?
- Q2: Как различить задачу на DP и greedy?
- Q3: Как перейти от рекуррентного решения к итеративному?

**Data Structures:**
- Q1: Какие базовые структуры данных знаешь?
- Q2: Когда использовать set vs map vs priority_queue?
- Q3: Как реализуется segment tree и для чего?

#### Советы по прохождению quiz

**DO:**
- ✅ Отвечай честно - это влияет на план тренировок
- ✅ "Не знаю" - нормальный ответ, лучше чем догадки
- ✅ Приводи примеры задач где применяется
- ✅ Объясняй своими словами, не обязательно формально
- ✅ Развёрнутые ответы → выше confidence

**DON'T:**
- ❌ Не гугли ответы - это бессмысленно
- ❌ Не завышай уровень - иначе план будет неадекватным
- ❌ Не спеши - подумай над вопросом

### Шаг 6: Предпочтения тренировок

```
Настройки плана тренировок:

1. Целевой рейтинг: (текущий: 1456)
   [Введи число, например 1600, или нажми Enter для 1656]
```

**Рекомендации:**
- +200-300 от текущего - реалистичная цель
- Не завышай слишком сильно - план будет слишком сложным

```
2. Сколько задач в неделю готов решать?
   [Рекомендую 10-15 для стабильного прогресса]
```

**Рекомендации:**
- 5-7 задач - медленный прогресс
- 10-15 задач - оптимально
- 20+ задач - только если есть много времени

```
3. Стратегия тренировок:
   1) Сбалансированная - mix сильных и слабых тем
   2) Фокус на слабых - приоритет самым слабым темам
   3) Челлендж - задачи выше текущего уровня

   Выбери номер (1-3):
```

**Стратегии:**

| Стратегия | Описание | Для кого |
|-----------|----------|----------|
| Сбалансированная | Mix сильных и слабых тем | Стабильный рост, разнообразие |
| Фокус на слабых | Только слабые темы | Быстро подтянуть слабости |
| Челлендж | Задачи на +100-200 выше рейтинга | Опытные, хотят выйти из зоны комфорта |

## Переинициализация

### Когда переинициализировать?

**Причины:**
- Сильно изменился уровень (вырос рейтинг на 300+)
- Профиль создан давно и неактуален
- Хочешь пересдать quiz для новой оценки

**Команда:**
```
/coach init
```

**Внимание:** Это перезапишет:
- Все оценки (topic_confidence)
- План тренировок
- Настройки

**Сохранится:**
- История сессий (session_history)
- Статистика практики и drill
- История контестов

## Частые вопросы

### Можно ли пропустить quiz?

**Нет.** Quiz - критическая часть для создания плана.

**Но можно:**
- Отвечать "не знаю" на всё → все темы получат confidence = 1
- Потом прогресс будет обновляться по мере тренировок

### Можно ли изменить ответы в quiz?

**Нет.** Но можно:
- `/coach init` - пройти заново
- `/coach reset {topic}` - сбросить прогресс по одной теме

### Сколько времени занимает инициализация?

**10-15 минут** в среднем:
- Шаги 1-3: 2-3 минуты
- Quiz (шаг 4): 5-10 минут
- Шаги 5-7: 2-3 минуты

### Что если CF API недоступен?

**Не проблема:**
- Введи "none" вместо handle
- Профиль создастся без CF данных
- Все фичи работают кроме синхронизации и анализа контестов
