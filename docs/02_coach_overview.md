# Обзор персонального тренера

## Что такое `/coach`?

`/coach` - это главная команда Claude Coach, которая запускает персонального тренера по спортивному программированию.

**Тренер - это не просто чат-бот.** Это система, которая:
- 📊 **Знает твой уровень** - на основе CF статистики и самооценки
- 🎯 **Видит твои слабые места** - темы с низким confidence
- 📅 **Составляет план** - персональный план тренировок под твою цель
- 📈 **Отслеживает прогресс** - фиксирует решённые задачи и рост confidence
- 💡 **Адаптируется** - план меняется по мере твоего роста

## Основная команда

```bash
/coach [аргумент]
```

### Без аргумента
```
/coach
```

**Что происходит:**
- Если профиля нет → **автоматическая инициализация**
- Если профиль есть → **интерактивное меню** с 8 режимами

### С аргументами

| Команда | Описание |
|---------|----------|
| `/coach` | Показать интерактивное меню |
| `/coach init` | Переинициализировать профиль |
| `/coach stats` | Показать статистику прогресса |
| `/coach sync` | Синхронизировать данные с Codeforces |
| `/coach plan` | Показать план тренировок |
| `/coach drill` | Набить код (автовыбор темы) |
| `/coach drill {topic}` | Набить конкретную тему |
| `/coach contest` | Проанализировать результаты контеста |
| `/coach reset {topic}` | Сбросить прогресс по теме |

## Режимы работы

### 1. 📚 ОБУЧЕНИЕ

**Для чего:** Изучение слабых тем с quiz и практикой

**Как работает:**
1. Тренер показывает список слабых тем (confidence < 6)
2. Выбираешь тему
3. Создаются/используются материалы (формат Zettelkasten)
4. Проходишь quiz (5 вопросов)
5. Решаешь практическую задачу
6. Смотришь готовый код в библиотеке
7. Обновляется confidence по теме

**Результат:**
- Повышение confidence (+1-2)
- Новые материалы в `editorials/{topic}/`
- Код в `library/{lang}/{topic}/`
- Запись в историю сессий

**Когда использовать:**
- Хочешь подтянуть слабую тему
- Изучаешь что-то новое
- Нужно освежить знания

**Детали:** [Режим обучения](04_coach_learning.md)

### 2. 💻 ПРАКТИКА

**Для чего:** Решение задач с консультацией тренера

**Как работает:**
1. Тренер рекомендует задачу (или ты даешь свою ссылку)
2. Решаешь задачу, тренер консультирует только когда спрашиваешь
3. После AC - краткий разбор
4. Обновляется confidence и статистика
5. Опционально: детальный editorial

**Результат:**
- Решённая задача
- Краткий разбор (что получилось, что нет)
- Обновление confidence (+1)
- Опционально: детальный editorial в `editorials/`

**Когда использовать:**
- Хочешь решить задачу с поддержкой
- Застрял на задаче
- Нужна рекомендация на слабую тему

**Детали:** [Режим практики](05_coach_practice.md)

### 3. 🔨 DRILL (набивашки)

**Для чего:** Тренировка мышечной памяти

**Как работает:**
1. Тренер показывает метаданные алгоритма (без кода!)
2. Набиваешь код по памяти в `solution/cpp/task.cpp` (или `solution/py/main.py`)
3. Говоришь "готово"
4. Тренер читает файл и семантически сравнивает с эталоном
5. Даёт обратную связь (что верно, что пропущено)
6. Показывает эталон

**Результат:**
- Тренировка мышечной памяти
- Запись в `drill_history` (accuracy)
- **НЕ влияет на confidence** - это тренировка, не изучение

**Когда использовать:**
- Знаешь алгоритм теоретически, но набиваешь медленно
- Перед контестом - разогреть руки
- Регулярно для поддержания мышечной памяти

**Детали:** [Режим drill](06_coach_drill.md)

### 4. 📊 CONTEST (анализ контеста)

**Для чего:** Разбор участия в контестах

**Как работает:**
1. Вставляешь ссылку на контест в `solution/CONTEST.md`
2. Указываешь тип: `solo` (индивидуальный) или `team` (командный)
3. Запускаешь `/coach contest`
4. Тренер загружает результаты через CF API
5. Задаёт вопросы о нерешённых задачах
6. Анализирует стратегию и распределение времени
7. Создаёт детальный разбор

**Результат:**
- Файл анализа в `editorials/{contest_id}_analysis.md`
- Запись в `contest_history` или `team_contest_history`
- Конкретные рекомендации что подтянуть
- Понимание стратегических ошибок

**Когда использовать:**
- После каждого контеста для извлечения уроков
- Для выявления повторяющихся ошибок
- Для улучшения стратегии

**Детали:** [Анализ контестов](07_coach_contest.md)

### 5. 📈 STATS (статистика)

**Для чего:** Просмотр прогресса

**Что показывает:**
- Handle и рейтинг на CF
- Уровень по каждой теме (confidence 1-10)
- Количество решённых задач
- Статистика сессий (обучение, практика, drill)
- История контестов

**Команда:**
```
/coach stats
```

или выбери "5" в меню

**Детали:** [Статистика и команды](08_coach_stats.md)

### 6. 📅 PLAN (план тренировок)

**Для чего:** Просмотр текущего плана

**Что показывает:**
- Текущая фаза (fundamentals/intermediate/advanced/expert)
- Целевой рейтинг
- Приоритетные темы на основе слабых мест
- Рекомендации по количеству задач в неделю
- Стратегия (balanced/focus/challenge)

**Команда:**
```
/coach plan
```

или выбери "6" в меню

**Детали:** [Статистика и команды](08_coach_stats.md)

### 7. 🔄 SYNC (синхронизация)

**Для чего:** Обновление статистики с Codeforces

**Что делает:**
- Загружает свежие данные с CF через API
- Обновляет рейтинг
- Обновляет список решённых задач
- Обновляет распределение тем

**Команда:**
```
/coach sync
```

или выбери "7" в меню

**Рекомендуется:** Синхронизировать раз в неделю

**Детали:** [Статистика и команды](08_coach_stats.md)

### 8. ⚙️ НАСТРОЙКИ

**Для чего:** Управление профилем

**Доступные действия:**
- Изменить целевой рейтинг
- Изменить стратегию тренировок
- Изменить количество задач в неделю
- Сбросить прогресс по теме: `/coach reset {topic}`
- Переинициализировать профиль: `/coach init`

## Как работает профиль?

### Файлы профиля

**coach/core.json** - основной профиль:
- Информация о пользователе (handle, preferred_language)
- Оценка знаний (topic_confidence для 10 тем)
- План тренировок (фаза, цель, стратегия)
- История сессий обучения (что изучал, результаты quiz)

**coach/stats.json** - статистика:
- CF данные (рейтинг, решённые задачи, теги)
- История практики (решённые задачи, попытки)
- История drill (набитые темы, accuracy)
- История контестов (solo и team)

### Обновление confidence

**Как растет уровень по темам:**

| Действие | Изменение confidence |
|----------|---------------------|
| Quiz в обучении (5/5) | +2 |
| Quiz в обучении (3-4/5) | +1 |
| Quiz в обучении (0-2/5) | 0 |
| Решение задачи в практике | +1 |
| Drill | 0 (не влияет) |

**Важно:** Рост постепенный - тема не станет сильной за одну сессию

### Определение слабых тем

**Слабая тема** - это тема с `confidence < 6`

**Приоритетные слабые темы:**
1. Берём все темы с confidence < 6
2. Сортируем по confidence (самые слабые первые)
3. Фильтруем по фокусу текущей фазы
4. Топ-3 становятся приоритетом

### Фазы подготовки

| Рейтинг | Фаза | Фокус |
|---------|------|-------|
| < 1200 | fundamentals | implementation, binary_search, greedy, two_pointers |
| 1200-1599 | intermediate | dp, graphs, data_structures, number_theory |
| 1600-1999 | advanced | advanced_dp, segment_tree, strings, dsu |
| ≥ 2000 | expert | advanced_structures, flows, geometry, fft |

**План адаптируется:** По мере роста рейтинга фаза меняется автоматически

## Типичный рабочий процесс

### Еженедельный цикл

```
Понедельник - Обучение
├─ /coach → режим ОБУЧЕНИЕ
├─ Изучить слабую тему
├─ Пройти quiz
└─ Решить практическую задачу

Вторник-Четверг - Практика
├─ /coach → режим ПРАКТИКА
├─ Решить рекомендованные задачи (2-3 в день)
└─ Фиксировать разборы

Пятница - Drill
├─ /coach drill
├─ Набить 2-3 алгоритма по памяти
└─ Разогреться перед контестом

Выходные - Контест
├─ Участие в CF/AtCoder контесте
├─ /coach contest
└─ Разбор результатов и ошибок
```

### После решения задачи

```
1. Решил задачу (AC) → запиши в практику
2. Не решил → найди разбор → вставь в PROBLEM.md → изучи
3. Если тема новая → /coach → ОБУЧЕНИЕ → изучи тему
4. Если тема знакомая → добавь в library/ (если нужно)
```

### Перед контестом

```
1. /coach drill → набить 2-3 алгоритма
2. Проверить library/ → убедись что всё на месте
3. Решить 1-2 warmup задачи
```

### После контеста

```
1. Вставить ссылку в solution/CONTEST.md
2. /coach contest
3. Ответить на вопросы о нерешённых задачах
4. Изучить анализ → определить слабые места
5. На следующей неделе → фокус на выявленные темы
```

## Преимущества подхода

### vs Традиционное решение задач

**Традиционно:**
- Решаешь задачи вслепую
- Не знаешь слабые места объективно
- Прогресс трудно измерить

**С `/coach`:**
- План на основе слабых мест
- Объективная оценка (confidence)
- Чёткое отслеживание прогресса

### vs Обычный Claude

**Обычный Claude:**
- Даёт решение, но нет плана
- Не отслеживает прогресс
- Каждый раз начинаешь с нуля

**С `/coach`:**
- Помнит твой уровень
- Адаптирует рекомендации
- Фиксирует историю

## Частые вопросы

### Можно ли использовать без Codeforces?

**Да!** При инициализации введи `none` вместо handle.

**Ограничения:**
- Нет анализа CF статистики
- Нет синхронизации
- Нет анализа контестов

**Доступно:**
- Оценка через quiz
- Режимы обучения, практики, drill
- Все фичи кроме CF интеграции

### Как часто синхронизироваться с CF?

**Рекомендуется:** Раз в неделю после контеста

**Почему не чаще:**
- CF API имеет rate limit
- Статистика меняется не так быстро

### Что если забыл про тренера и долго не использовал?

**Без проблем!**
- Запусти `/coach sync` для обновления CF данных
- Профиль сохраняется
- План остаётся актуальным

**Если уровень сильно изменился:**
- `/coach init` для переинициализации

### Можно ли изменить план?

**Да!**
- `/coach` → режим 8 (НАСТРОЙКИ)
- Изменить целевой рейтинг
- Изменить стратегию
- Изменить количество задач в неделю

### Что делать если confidence неправильный?

**Вручную не изменить**, но можно:
- `/coach reset {topic}` - сбросить прогресс по теме
- `/coach init` - переинициализировать весь профиль
- Пройти больше quiz/задач для корректировки
