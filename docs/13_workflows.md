# Типичные сценарии использования

## Обзор

Здесь собраны типичные рабочие процессы использования Claude Coach в разных ситуациях.

## Сценарий 1: Первый запуск

**Цель:** Начать работу с системой с нуля.

### Шаги

```bash
# 1. Клонировать/создать репозиторий
git clone <repo-url>
cd competitive

# 2. Запустить Claude Code
claude

# 3. Инициализировать тренера
/coach

# 4. Пройти инициализацию
# - Указать CF handle (или none)
# - Пройти quiz по 10 темам
# - Настроить план тренировок

# 5. Готово! Профиль создан
```

**Время:** 15-20 минут.

**Результат:**
- `coach/core.json` - профиль
- `coach/stats.json` - статистика
- План тренировок готов

## Сценарий 2: Обучающая сессия

**Цель:** Изучить слабую тему.

### Шаги

```bash
# 1. Запустить тренера
/coach

# 2. Выбрать режим обучения (1)

# 3. Выбрать тему (например, greedy)

# 4. Изучить материалы
# - Читай editorials/greedy/index.md
# - Изучай заметки по порядку

# 5. Пройти quiz (5 вопросов)

# 6. Решить практическую задачу (опционально)

# 7. Посмотреть код в библиотеке
```

**Время:** 20-30 минут.

**Результат:**
- Confidence по теме +1-2
- Материалы в editorials/
- Код в library/

## Сценарий 3: Практическая сессия

**Цель:** Решить 3-5 задач на слабые темы.

### Шаги

```bash
# 1. Запустить тренера
/coach

# 2. Выбрать режим практики (2)

# 3. Для каждой задачи:
#    - Получить рекомендацию (или вставить свою)
#    - Решать с консультацией Claude
#    - После AC → краткий разбор
#    - Опционально: детальный editorial

# 4. Повторить 3-5 раз
```

**Время:** 1-2 часа.

**Результат:**
- 3-5 решённых задач
- Confidence +1 по каждой теме
- Краткие разборы

## Сценарий 4: Подготовка к контесту

**Цель:** Разогреть руки перед контестом.

### Шаги

```bash
# 1. За день до контеста
# - /coach drill (2-3 часто используемых алгоритма)
# - Проверить library/ (всё на месте)
# - Решить 1-2 warmup задачи

# 2. В день контеста (за 30-60 минут)
# - /coach drill (ещё 2-3 алгоритма)
# - Прочитать index.md по слабым темам
# - Проверить шаблон в solution/cpp/task.cpp
```

**Время:** 30-60 минут.

**Результат:** Руки разогреты, библиотека проверена.

## Сценарий 5: Анализ контеста

**Цель:** Разобрать участие в контесте.

### Шаги

```bash
# 1. Сразу после контеста
# - Заполнить solution/CONTEST.md
#   - Ссылка на контест
#   - Тип: solo или team
#   - Handle (+ участники для team)

# 2. Запустить анализ
/coach contest

# 3. Ответить на вопросы
# - Почему не получились задачи?
# - Что пробовал?
# - Где застрял?

# 4. Изучить анализ
# - editorials/{id}_analysis.md
# - Выявленные слабости
# - Рекомендации

# 5. Действия после анализа
# - /coach → обучение (слабые темы)
# - Дорешать задачи
# - Решить 2-3 похожие
```

**Время:** 20-30 минут.

**Результат:**
- Детальный анализ контеста
- План действий для улучшения

## Сценарий 6: Дорешивание после контеста

**Цель:** Решить задачи которые не получились на контесте.

### Шаги

```bash
# 1. Для каждой нерешённой задачи:

# 2. Вставить ссылку в solution/PROBLEM.md

# 3. Найти официальный разбор

# 4. Вставить разбор в PROBLEM.md (секция "Разбор")

# 5. Попросить Claude объяснить
> Объясни solution/PROBLEM.md

# 6. Реализовать решение самому

# 7. Создать детальный editorial

# 8. Добавить в библиотеку (если новая техника)
```

**Время:** 30-60 минут на задачу.

**Результат:**
- Понимание решения
- Детальный editorial
- Обновлённая библиотека

## Сценарий 7: Недельный цикл

**Цель:** Регулярная тренировка по плану.

### Понедельник: Обучение

```bash
/coach → ОБУЧЕНИЕ → слабая тема
# 20-30 минут
```

### Вторник-Четверг: Практика

```bash
/coach → ПРАКТИКА → 2-3 задачи в день
# 1-2 часа в день
```

### Пятница: Drill

```bash
/coach drill (3-4 алгоритма)
# 20-30 минут
```

### Суббота: Контест

```bash
# Участие в Codeforces/AtCoder контесте
# 2-3 часа
```

### Воскресенье: Анализ + дорешивание

```bash
/coach contest
# Дорешать нерешённые задачи
# 2-3 часа
```

**Итого в неделю:** 8-12 часов тренировок.

## Сценарий 8: Изучение новой темы

**Цель:** Глубоко изучить тему с нуля.

### Шаги

```bash
# День 1: Обучение
/coach → ОБУЧЕНИЕ → новая тема
# - Материалы создаются автоматически
# - Quiz + практическая задача

# День 2: Практика
/coach → ПРАКТИКА → 3-4 задачи на тему
# - Закрепление понимания

# День 3: Drill
/coach drill тема
# - Набивание реализации по памяти
# - 2-3 раза до 90%+ точности

# День 4-5: Больше практики
# - Решить ещё 5-7 задач разной сложности
# - Создать editorials для сложных

# День 6-7: Повторение
# - Перечитать materials
# - Повторный quiz
# - Drill для закрепления
```

**Время:** Неделя интенсивной работы.

**Результат:** Confidence 1-2 → 6-7.

## Сценарий 9: Командная тренировка

**Цель:** Подготовка команды к ICPC.

### Еженедельный процесс

```bash
# Индивидуально (каждый участник):
# - Обучение (слабые темы)
# - Практика (5-10 задач)
# - Drill (2-3 раза)

# Вместе (команда):
# 1. Виртуальный контест (3 часа)

# 2. Анализ контеста
# - Заполнить solution/CONTEST.md (type: team)
# - /coach contest
# - Обсудить дублирование усилий
# - Выявить слабости команды

# 3. Дорешивание
# - Распределить задачи между участниками
# - Каждый дорешивает свои
# - Обсуждение решений

# 4. Планирование
# - Определить роли (кто какие темы берёт)
# - План индивидуального изучения
```

**Результат:** Синергия команды, меньше дублирования.

## Сценарий 10: Быстрая консультация

**Цель:** Решить задачу без полноценной сессии.

### Шаги

```bash
# 1. Вставить ссылку в solution/PROBLEM.md
# - Оставить "Разбор" пустым

# 2. Открыть Claude Code
> Читай solution/PROBLEM.md

# 3. Решать задачу, задавать вопросы

# 4. После AC
> Создай краткий разбор (не нужен детальный editorial)
```

**Время:** 15-30 минут.

**Результат:** Задача решена, без фиксации в статистике.

## Советы по workflow

### Ежедневно

- 5-10 минут: просмотр плана (`/coach plan`)
- 1-2 часа: практика
- 10-15 минут: drill (не обязательно каждый день)

### Еженедельно

- 20-30 минут: обучение новой теме
- 10-20 минут: синхронизация (`/coach sync`)
- 20-30 минут: анализ контеста

### Ежемесячно

- Ревью статистики (`/coach stats`)
- Обновление целевого рейтинга
- Проверка библиотеки (всё актуально?)
