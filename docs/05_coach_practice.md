# Режим практики

## Что такое режим практики?

Режим практики - это решение задач с консультацией тренера, который помогает только когда ты спрашиваешь.

**Цель режима:**
- Решить задачу самостоятельно с минимальной помощью
- Получить рекомендацию на слабую тему
- Зафиксировать прогресс и обновить confidence
- Создать краткий или детальный разбор (опционально)

## Отличие от обычного использования Claude

### Обычный Claude

```
Пользователь: Помоги с задачей X
Claude: [Сразу даёт решение или наводящие вопросы]
```

### Режим практики

```
Пользователь: [Решает задачу]
Claude: [Молчит, ждёт когда спросят]
Пользователь: Правильно ли что...?
Claude: [Отвечает только на вопрос, не ведёт за руку]
```

**Ключевая философия:** Тренер - консультант, а не решатель. Ты решаешь сам, тренер только отвечает на вопросы.

## Когда использовать?

- Хочешь решить задачу с поддержкой
- Застрял на задаче и нужна помощь
- Нужна рекомендация задачи на слабую тему
- Хочешь чтобы прогресс был зафиксирован
- После контеста - дорешать задачи

## Как запустить?

### Через интерактивное меню

```
/coach
```

Выбери пункт **2. ПРАКТИКА** из меню.

### Прямой запуск

Режим практики можно запустить только через меню `/coach`, прямой команды нет.

### Шаг 2: Решение задачи

После выбора задачи начинается процесс решения.

**Режим работы тренера:**
- Молчит и ждёт пока ты спрашиваешь
- Не даёт подсказок проактивно
- Не подтверждает и не опровергает наблюдения без вопроса
- Отвечает только на конкретные вопросы

#### Примеры вопросов

**Хорошие вопросы (конкретные):**

```
> Правильно ли я понимаю что нужно использовать
  массив из 26 счётчиков?

Bot: Да, массив из 26 счётчиков — верное наблюдение.
     Какую сложность это даст на один запрос?
```

```
> Как оптимально хранить состояния DP?

Bot: Для этой задачи достаточно двух массивов:
     dp[0] и dp[1] для текущего и предыдущего слоя.
     Это даст O(n) по памяти.
```

```
> Я застрял. Не понимаю как обработать случай когда...

Bot: В этом случае нужно рассмотреть две ветки:
     1) Если условие X выполнено
     2) Если условие X не выполнено
     Какая из них применима к твоему случаю?
```

**Плохие вопросы (слишком общие):**

```
> Как решать эту задачу?

Bot: Попробуй сначала сформулировать что ты понял из условия.
     Какие наблюдения у тебя есть?
```

```
> Дай подсказку

Bot: Лучше задай конкретный вопрос - где именно застрял?
```

#### Запоминание хода решения

**Важно:** Тренер запоминает весь диалог для итогового разбора:
- Какие наблюдения были сделаны
- Где произошла ошибка в логике
- Какие вопросы привели к прорыву
- Сколько времени потрачено
- Сколько попыток было

## Типы рекомендаций

### По слабым темам

**Алгоритм:**
1. Берёт топ-3 слабые темы (confidence < 6)
2. Для каждой темы находит задачи:
   - Рейтинг: твой_рейтинг ± 100
   - Теги соответствуют теме
   - Ещё не решал (проверка по CF)
3. Предлагает 1-2 задачи на выбор

### По плану тренировок

**Алгоритм:**
1. Смотрит недельный план (problems_per_week)
2. Считает сколько решено на этой неделе
3. Выбирает тему из приоритетных (focus_areas)
4. Рекомендует задачу с учётом:
   - Баланс тем (не все задачи на одну тему)
   - Прогресс по фазе
   - Стратегия (balanced/focus/challenge)

### По сложности

Если strategy = "challenge":
- Рейтинг задач: твой_рейтинг + 100...200
- Более сложные паттерны
- Комбинация нескольких техник

Если strategy = "balanced":
- Рейтинг задач: твой_рейтинг ± 100
- Mix простых и средних

Если strategy = "focus":
- Только слабые темы
- Рейтинг: твой_рейтинг ± 50

## Частые вопросы

### Можно ли решать без тренера?

**Да!** Режим практики опционален.

Можно:
- Решать задачи как обычно
- Использовать обычного Claude
- Вставлять ссылку в solution/PROBLEM.md и работать без `/coach`

**Преимущества режима практики:**
- Прогресс фиксируется автоматически
- Confidence обновляется
- Статистика собирается
- Персональные рекомендации

### Сколько задач нужно решать в неделю?

**Зависит от плана:**
- Указал 10 задач в неделю → рекомендуется 10
- Указал 15 задач → рекомендуется 15

**Минимум:** 5 задач в неделю для видимого прогресса

**Оптимум:** 10-15 задач в неделю

### Что если застрял на задаче долго?

**Правило 20 минут:**
- Если нет прогресса 20 минут → подсказка или другая задача
- Лучше решить 2 простые задачи, чем застрять на 1 сложной

**Исключение:**
- Контест (нужно дорешать)
- Важная тема (стоит потратить время)

### Влияет ли количество попыток на confidence?

**Нет.**

Confidence растёт на +1 при AC, независимо от:
- Количества попыток (WA, TLE, etc.)
- Времени решения
- Количества вопросов тренеру

**Важен только факт:** Решил сам = +1 к confidence.

### Можно ли решать задачи вне рекомендаций?

**Да, конечно!**

Рекомендации - это помощь, а не ограничение.

Можно:
- Решать любые задачи с любых платформ
- Вставлять ссылку в практику
- Прогресс всё равно фиксируется

### Как часто нужно практиковаться?

**Рекомендуется:**
- 2-3 задачи каждый день
- Или 5-7 задач 2 раза в неделю

**Минимум:**
- 5 задач в неделю

**Для быстрого роста:**
- 15-20 задач в неделю
- Фокус на слабые темы

### Что делать если все задачи слишком сложные?

**Скажи тренеру:**
```
Все задачи слишком сложные, дай попроще
```

Тренер:
- Снизит рейтинг рекомендаций на 100-200
- Предложит задачи на базовые темы
- Может рекомендовать обучение вместо практики

## Советы по эффективной практике

### Перед решением задачи

1. **Прочитай условие внимательно** - не спеши к коду
2. **Сформулируй наблюдения** - что заметил из условия
3. **Определи тип задачи** - какие теги/техники применимы
4. **Оцени сложность** - сколько времени потребуется

### Во время решения

1. **Думай вслух** - формулируй мысли письменно
2. **Задавай конкретные вопросы** - не "дай подсказку", а "правильно ли что..."
3. **Проверяй edge cases** - пустой ввод, максимум, минимум
4. **Тестируй локально** - не отправляй сразу

### После AC

1. **Пойми почему получилось** - не просто "сработало"
2. **Запиши ключевую идею** - в разборе
3. **Добавь в библиотеку** - если новая техника
4. **Решить похожую задачу** - для закрепления

### После неудачи

1. **Не расстраивайся** - это нормально
2. **Изучи разбор** - вставь в PROBLEM.md
3. **Пойми пропущенный шаг** - создай детальный editorial
4. **Повтори тему** - `/coach` → обучение
5. **Решить похожую задачу** - для компенсации
