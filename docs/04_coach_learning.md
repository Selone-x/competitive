# Режим обучения

## Что такое режим обучения?

Режим обучения - это структурированный процесс изучения слабых тем с проверкой понимания и практикой.

**Цель режима:**
- Подтянуть слабые темы (confidence < 6)
- Создать или использовать материалы в формате Zettelkasten
- Проверить понимание через quiz
- Закрепить знания практической задачей
- Обновить уровень (confidence) по теме

## Когда использовать?

- Хочешь подтянуть слабую тему
- Изучаешь что-то новое
- Нужно освежить знания
- Тренер рекомендует изучить тему после контеста
- Confidence по теме < 6

## Как запустить?

### Через интерактивное меню

```
/coach
```

Выбери пункт **1. ОБУЧЕНИЕ** из меню.

### Прямой запуск

Режим обучения можно запустить только через меню `/coach`, прямой команды нет.

## Процесс обучения

### Шаг 1: Выбор темы

```
📚 РЕЖИМ ОБУЧЕНИЯ

Твои слабые темы (confidence < 6):

1. greedy (confidence: 3/10) ⚠️
2. number_theory (confidence: 2/10) ⚠️
3. dp (confidence: 4/10) ⚠️
4. strings (confidence: 3/10) ⚠️
5. geometry (confidence: 1/10) ⚠️

Выбери номер темы (1-5) или введи название:
```

**Что происходит:**
- Показываются все темы с confidence < 6
- Сортировка по приоритету (самые слабые первые)
- Можно выбрать по номеру или написать название темы

**Приоритет тем:**
1. Темы из плана тренировок (фокус фазы)
2. Самые слабые темы (confidence 1-3)
3. Темы с предыдущими неусвоенными подтопиками

### Шаг 2: Загрузка или создание материалов

#### Если материалы уже есть

```
Материалы по теме "greedy" найдены в editorials/greedy/

Используем существующие материалы.
```

Тренер использует файлы из `editorials/greedy/`.

#### Если материалов нет

```
Материалы по теме "greedy" не найдены.

Создаю структурированные материалы в формате Zettelkasten...

✅ Материалы созданы!

Структура:
- editorials/greedy/index.md (карта знаний)
- editorials/greedy/01_what_is_greedy.md
- editorials/greedy/02_when_to_use.md
- editorials/greedy/03_correctness_proof.md
- editorials/greedy/04_common_patterns.md
- editorials/greedy/05_vs_dp.md
```

**Формат Zettelkasten:**
- Атомарные заметки (одна концепция = один файл)
- Интуитивные объяснения с примерами
- Ссылки на связанные заметки
- index.md - карта навигации

### Шаг 3: Изучение материалов

```
Давай изучим тему "greedy"!

📖 Карта знаний:
(показывается содержимое index.md)

Основные концепции:
1. Что такое жадный алгоритм
2. Когда применять
3. Как доказывать корректность
4. Типичные паттерны
5. Greedy vs DP

Прочитай материалы и дай знать когда готов к проверке понимания.
```

**Что делать:**
- Прочитай index.md для общего понимания
- Изучи заметки по порядку
- Обращай внимание на примеры и связи
- Не спеши - лучше понять глубоко, чем быстро

### Шаг 4: Quiz (проверка понимания)

```
Отлично! Проверим понимание темы через quiz.

5 вопросов, каждый привязан к подтопику:
- definition (определение)
- use_cases (применение)
- implementation (реализация)
- pattern_matching (распознавание паттернов)
- edge_cases (граничные случаи)

Готов начать? (да/нет)
```

#### Структура quiz

**5 вопросов по подтопикам:**

1. **definition** - что это и как работает
2. **use_cases** - когда применять
3. **implementation** - как реализовать
4. **pattern_matching** - как распознать в задаче
5. **edge_cases** - частые ошибки и граничные случаи

**Особенность:** Если изучал тему раньше и есть слабые подтопики, вопросы на них идут первыми.

#### Пример quiz

```
Вопрос 1/5 (definition):
Что такое жадный алгоритм? Как он принимает решения?

> [Твой ответ]

✓ Верно! Жадный алгоритм выбирает локально оптимальное решение
на каждом шаге, надеясь получить глобальный оптимум.

Вопрос 2/5 (use_cases):
Как отличить задачу на greedy от задачи на DP?

> [Твой ответ]

✓ Хороший ответ! Если выбор на текущем шаге не зависит от будущих
состояний и можно доказать что локальный оптимум → глобальный,
то это greedy. Если нужна оптимизация по всем состояниям → DP.

Вопрос 3/5 (implementation):
...
```

#### Оценка результата

```
Quiz завершен!

Результат: 4/5 ✅

Усвоенные подтопики:
✅ definition - отлично понял
✅ use_cases - уверенно применяешь
✅ implementation - без проблем
✅ pattern_matching - хорошо распознаёшь

Стоит повторить:
⚠️ edge_cases - не все граничные случаи учёл

Confidence обновлён: 3 → 5 (+2)
```

**Критерии обновления:**
- 5/5 правильных → +2 к confidence
- 3-4/5 правильных → +1 к confidence
- 0-2/5 правильных → 0 (без изменений)

**Запись в профиль:**
```json
{
  "session_history": [
    {
      "type": "learning",
      "topic": "greedy",
      "date": "2026-02-08T10:30:00Z",
      "quiz_result": 4,
      "quiz_total": 5,
      "learned_subtopics": ["definition", "use_cases", "implementation", "pattern_matching"],
      "weak_subtopics": ["edge_cases"],
      "confidence_before": 3,
      "confidence_after": 5
    }
  ]
}
```

### Шаг 5: Практическая задача

```
Отлично! Теперь закрепим знания на практике.

Рекомендую задачу на тему "greedy":

   Рейтинг: 1400
   Ссылка: https://codeforces.com/problemset/problem/1234/C

на каждом шаге.

Хочешь решить эту задачу сейчас или пропустить? (решить/пропустить)
```

**Если "решить":**
- Переход в режим практики для этой задачи
- После AC - возврат к режиму обучения

**Если "пропустить":**
- Переход к следующему шагу

## Адаптивное обучение

### Повторное изучение темы

Если возвращаешься к теме, которую уже изучал:

```
Тему "greedy" ты изучал 2026-02-01.

Прошлый результат: 4/5
Слабый подтопик: edge_cases

Хочешь:
1. Повторить весь материал с quiz
2. Сразу к quiz (фокус на слабых подтопиках)
3. Только изучить слабые подтопики

Выбери вариант (1-3):
```

**Вариант 2 (рекомендуется):**
- Quiz начинается с вопросов по слабым подтопикам
- Если ответил правильно → остальные подтопики
- Экономия времени, фокус на пробелах

### Прогрессивное повышение сложности

По мере роста confidence:

**Confidence 1-3 (новичок):**
- Базовые концепции и простые примеры
- Quiz: базовые вопросы
- Задачи: рейтинг 800-1200

**Confidence 4-6 (знаком):**
- Паттерны и нетривиальные случаи
- Quiz: применение и распознавание
- Задачи: рейтинг 1200-1500

**Confidence 7-8 (уверенно):**
- Edge cases и оптимизации
- Quiz: сложные случаи и доказательства
- Задачи: рейтинг 1500-1800

**Confidence 9-10 (эксперт):**
- Обучение не требуется
- Только практика для поддержания

## Частые вопросы

### Можно ли пропустить quiz?

**Нет.** Quiz - обязательная часть для обновления confidence.

Без quiz сессия не считается завершённой и confidence не обновится.

### Что если провалил quiz (0-2/5)?

**Не страшно!**
- Confidence не упадёт (только не растёт)
- Тренер покажет правильные ответы
- Рекомендует повторить материалы
- Можно пройти сессию снова позже

### Сколько времени занимает сессия?

**15-30 минут в среднем:**
- Изучение материалов: 5-10 минут
- Quiz: 5-10 минут
- Практическая задача: опционально (можно пропустить)
- Просмотр кода: 2-3 минуты

### Можно ли изучить несколько тем подряд?

**Можно**, но не рекомендуется.

**Лучше:**
- 1 тема в день для глубокого понимания
- Чередовать обучение и практику
- Дать мозгу время усвоить информацию

**Оптимальный цикл:**
```
День 1: Обучение (тема A)
День 2: Практика (задачи на тему A)
День 3: Обучение (тема B)
День 4: Практика (задачи на тему B)
День 5: Drill (набивашки)
...
```

### Что если материалы неполные или непонятные?

**Скажи тренеру:**
```
Материалы по "geometry" непонятные, можешь объяснить подробнее?
```

Тренер:
- Объяснит концепцию другими словами
- Даст дополнительные примеры
- Может пересоздать материалы (если нужно)

### Нужно ли читать все заметки?

**Да, рекомендуется.**

Но можно:
- Сначала прочитать index.md для общего понимания
- Затем заметки по порядку
- Пропустить очевидные концепции (если уверен)

**Важно:** Quiz проверяет все подтопики, так что пропуск может снизить результат.

### Можно ли изучать темы вне плана?

**Да!** План - это рекомендация, а не ограничение.

**В меню обучения:**
- Показываются все слабые темы (не только из плана)
- Можно выбрать любую тему
- Но приоритетные (из плана) отмечены специально

### Влияет ли практическая задача на confidence?

**Нет, не влияет.**

Confidence обновляется только по результату quiz.

Практическая задача:
- Опциональная часть
- Для закрепления знаний
- Решённые задачи идут в статистику практики

### Можно ли вернуться к материалам позже?

**Да!** Материалы сохраняются в `editorials/{topic}/`.

Можно:
- Открыть файлы вручную и перечитать
- Запустить сессию обучения снова
- Использовать как справочник при решении задач

## Советы по эффективному обучению

### До сессии

1. **Выбери правильное время** - когда мозг свежий (утро/день)
2. **Убери отвлечения** - закрой соцсети, мессенджеры
3. **Подготовь код-редактор** - может понадобиться для примеров

### Во время сессии

1. **Не спеши** - лучше понять глубоко, чем пробежать быстро
2. **Делай заметки** - своими словами, это помогает запомнить
3. **Пробуй примеры** - запускай код из материалов локально
4. **Задавай вопросы** - если что-то непонятно

### После сессии

1. **Решить 2-3 задачи** на тему сразу после обучения
2. **Повторить через неделю** - закрепить знания
3. **Добавить в библиотеку** - свои реализации алгоритмов
4. **Использовать в контестах** - применять на практике
