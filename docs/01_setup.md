# Установка и настройка

## Требования

### Обязательно
- **Claude Code CLI** - основной инструмент
- **Python 3** - для скриптов интеграции с Codeforces API
- **Git** - для работы с репозиторием

### Рекомендуется
- **Компилятор C++** (g++, clang++) - если решаешь на C++
- **Аккаунт на Codeforces** - для анализа статистики и плана тренировок

## Шаг 1: Установка Claude Code CLI

### Скачивание

1. Перейди на [claude.ai/download](https://claude.ai/download)
2. Скачай версию для своей ОС (Windows/macOS/Linux)
3. Установи согласно инструкциям

### Проверка установки

```bash
claude --version
```

Должна отобразиться версия Claude Code CLI.

## Шаг 2: Клонирование репозитория

```bash
# Клонируй репозиторий (замени URL на свой)
git clone <твой-репозиторий-url>

# Перейди в директорию
cd competitive
```

Если у тебя еще нет репозитория:

```bash
# Создай новую папку
mkdir competitive
cd competitive

# Инициализируй git
git init

# Скопируй структуру проекта отсюда или создай вручную
```

## Шаг 3: Структура директорий

Убедись что у тебя есть следующие директории:

```
competitive/
├── .claude/
│   └── skills/
│       └── competitive-coach/    # Skill тренера (должен быть скопирован)
├── library/
│   ├── cpp/                      # Будет заполняться по мере обучения
│   └── py/
├── solution/
│   ├── cpp/
│   │   └── task.cpp              # Шаблон для C++ решений
│   └── py/
│       └── main.py               # Шаблон для Python решений
├── editorials/
│   └── examples/                 # Примеры форматов (уже есть)
├── docs/                         # Эта документация
├── claude.md                     # Контекст для Claude
└── README.md
```

**Создай недостающие директории:**

```bash
mkdir -p library/cpp library/py
mkdir -p solution/cpp solution/py
mkdir -p editorials/examples
mkdir -p coach  # Для профиля тренера
```

## Шаг 5: Проверка Python и зависимостей

Убедись что Python 3 установлен:

```bash
python3 --version
```

**Требуемая версия:** Python 3.6 или выше

**Зависимости:** Скрипт `codeforces_api.py` использует только стандартную библиотеку Python, дополнительные пакеты не нужны.

## Шаг 6: Первый запуск Claude Code

Запусти Claude Code в директории проекта:

```bash
cd /path/to/competitive
claude
```

Должно открыться интерактивное окно Claude Code CLI.

## Шаг 7: Инициализация тренера

### Первый запуск

В Claude Code выполни:

```
/coach
```

**Что произойдет:**
1. Система обнаружит что профиля нет
2. Автоматически запустится процесс инициализации
3. Ты пройдешь несколько шагов (см. ниже)

### Процесс инициализации

#### Шаг 1: Приветствие
```
Привет! Я твой персональный тренер по спортивному программированию.

Работал ли ты уже со мной (Claude) для решения задач по CP? (да/нет)
```

Ответь честно - это влияет на ожидания тренера.

#### Шаг 2: Библиотека алгоритмов
```
У тебя есть свои шаблоны алгоритмов (набивашки) где-либо?
```

Если **да:**
- Скопируй свои файлы в `library/cpp/` (для C++) или `library/py/` (для Python)
- Скажи тренеру "готово"
- Тренер проверит и посчитает файлы

Если **нет:**
- Ничего страшного, библиотека будет заполняться по мере тренировок

#### Шаг 3: Codeforces handle
```
Укажи свой никнейм (handle) на Codeforces:
(Если нет аккаунта, введи "none")
```

Если **указал handle:**
- Система загрузит твою статистику через API
- Покажет рейтинг, количество решённых задач
- Определит частые и редкие темы

Если **none:**
- Работа без статистики CF
- Оценка знаний только через quiz

#### Шаг 4: Оценка знаний (quiz)
```
Начинаем оценку знаний!
Binary Search: Что такое бинарный поиск и когда он применяется?
```

**10 тем для оценки:**
1. Binary Search
2. Two Pointers
3. Sorting & Searching
4. Dynamic Programming
5. Graphs (DFS/BFS)
6. Greedy
7. Number Theory
8. Data Structures
9. Strings
10. Geometry

**Для каждой темы:**
- 2-3 вопроса (адаптивно, зависит от ответов)
- Оценка confidence: 1-10

**Советы:**
- Отвечай честно - это влияет на план тренировок
- "Не знаю" - нормальный ответ, лучше чем догадки
- Развёрнутые ответы с примерами → выше confidence

#### Шаг 5: Настройки плана
```
1. Целевой рейтинг: (текущий: 1200)
   [Введи число, например 1600]

2. Сколько задач в неделю готов решать?
   [Рекомендую 10-15]

3. Стратегия тренировок:
   1) Сбалансированная
   2) Фокус на слабых
   3) Челлендж
```

**Стратегии:**
- **Сбалансированная** - mix сильных и слабых тем
- **Фокус на слабых** - приоритет самым слабым темам (рекомендуется)
- **Челлендж** - задачи выше текущего уровня

#### Шаг 6: Готово!
```
✅ Профиль создан!

Фаза: intermediate
Цель: 1600
Приоритетные темы: dp, graphs, number_theory

Что делаем дальше?
1. ОБУЧЕНИЕ - изучить слабую тему
2. ПРАКТИКА - решить задачу
3. DRILL - набить код по памяти
```

**Файлы созданы:**
- `coach/core.json` - основной профиль (темы, план, настройки)
- `coach/stats.json` - статистика (история сессий, CF данные)

## Возможные проблемы

### Ошибка: "python3: command not found"

**Решение:**
- Windows: Установи Python с [python.org](https://www.python.org/downloads/)
- macOS: `brew install python3`
- Linux: `sudo apt install python3` (или аналог для твоего дистрибутива)

### Ошибка: "Codeforces API error"

**Причины:**
- Неправильный handle
- Проблемы с интернетом
- CF API временно недоступен

**Решение:**
- Проверь handle на Codeforces
- Попробуй позже
- Используй "none" если не критично

### Профиль не создается

**Решение:**
1. Проверь что папка `coach/` существует: `mkdir coach`
2. Проверь права доступа: `chmod 755 coach`
3. Попробуй снова: `/coach init`
