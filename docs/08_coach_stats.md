# Статистика и команды

## Обзор

Система статистики позволяет отслеживать прогресс, просматривать план тренировок и синхронизироваться с Codeforces.

**Доступные команды:**
- `/coach stats` - статистика прогресса
- `/coach plan` - план тренировок
- `/coach sync` - синхронизация с Codeforces
- `/coach reset {topic}` - сброс прогресса по теме

Все команды также доступны через меню `/coach` (пункты 5-8).

## /coach sync

Синхронизация данных с Codeforces через API.

### Что синхронизируется

- Текущий рейтинг и ранг
- Количество решённых задач
- Частые и редкие темы (теги)
- История контестов
- Изменение рейтинга

Загружаю данные для tourist...

**Рекомендуется:**
- После контеста
- Раз в неделю
- После решения большого количества задач

**Не чаще чем:**
- Раз в день (CF API имеет rate limit)

## /coach reset {topic}

Сброс прогресса по конкретной теме.

### Использование

```bash
/coach reset dp
/coach reset greedy
```

### Что происходит

```
⚠️ СБРОС ПРОГРЕССА: dp

Это действие:
- Сбросит confidence по теме dp (4 → 1)
- Удалит историю обучения по теме
- Сбросит статистику практики (не удалит, но пометит)

История сессий и задачи останутся для справки.

Подтвердить сброс? (да/нет)
```

**Если "да":**
```
✅ Прогресс по теме "dp" сброшен

confidence: 4 → 1
История обучения: 3 сессии → 0
Статистика практики: помечена как "после сброса"

Можешь начать изучение темы заново:
/coach → обучение → dp
```

### Когда использовать

- Неправильно оценил уровень в quiz
- Confidence завышен (решил задачи с подсказками)
- Хочешь переизучить тему с нуля
- Confidence не отражает реальный уровень

### Внимание

**Необратимая операция!** История не восстанавливается.

Лучше используй `/coach init` для полного переcоздания профиля.

## Настройки (меню пункт 8)

### Подменю настроек

```
⚙️ НАСТРОЙКИ

1. 🔄 INIT - переинициализировать профиль
2. ❌ RESET - сбросить прогресс по теме
3. ← НАЗАД - вернуться в главное меню

Выбери действие (1-3):
```

#### 1. INIT

Переинициализация профиля (аналогично `/coach init`).

**Внимание:** Перезапишет весь профиль!

#### 2. RESET

Выбор темы для сброса прогресса.

```
Введи название темы для сброса:
(binary_search, dp, greedy, graphs, etc.)
```

## Файлы профиля

### coach/core.json

Основной профиль:
- `user_info` - handle, preferred_language
- `knowledge_assessment` - topic_confidence
- `training_plan` - фаза, цель, стратегия
- `session_history` - история обучения

### coach/stats.json

Статистика:
- `practice_stats` - решённые задачи, попытки
- `drill_stats` - drill сессии, точность
- `contest_history` - solo контесты
- `team_contest_history` - team контесты
- `codeforces_sync` - данные из CF API

## Частые вопросы

### Как часто синхронизироваться?

**Оптимально:** Раз в неделю или после контеста.

**Не нужно:** После каждой задачи (CF API имеет лимиты).

### Что если забыл обновить статистику?

**Не проблема.** Запусти `/coach sync`.

Все изменения на CF загрузятся автоматически.

### Можно ли изменить целевой рейтинг?

**Да!** Через настройки (меню пункт 8) или вручную отредактировав `coach/core.json`.

При синхронизации целевой рейтинг автоматически корректируется (+200 от текущего).

### Влияет ли сброс темы на план?

**Да.** Тема с confidence 1 станет приоритетной в плане (как самая слабая).

### Можно ли экспортировать статистику?

**Да!** Файлы `coach/core.json` и `coach/stats.json` - обычный JSON.

Можно:
- Скопировать на другой компьютер
- Обработать скриптом
- Визуализировать в таблице/графике
