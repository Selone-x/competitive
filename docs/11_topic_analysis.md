# Изучение тем (Zettelkasten)

## Что такое Zettelkasten?

Zettelkasten - метод создания заметок, где каждая заметка содержит одну атомарную идею со связями на другие заметки.

**В Claude Coach:** Структурированные материалы для изучения тем CP.

**Формат:** `editorials/{topic}/`

**Пример:** `editorials/examples/topic_analysis_example/`

## Принципы Zettelkasten

### 1. Атомарность

**Одна заметка = одна концепция**

**Хорошо:**
- `01_prime_factorization.md` - что такое факторизация
- `02_trial_division.md` - алгоритм пробного деления
- `03_optimizations.md` - оптимизации (до √n)

**Плохо:**
- `number_theory.md` - всё про теорию чисел (слишком большое)

### 2. Интуитивность

**Объяснения на простом языке, без формализмов**

**Хорошо:**
```markdown
Бинарный поиск - это как искать слово в словаре:
открываешь посередине, смотришь больше или меньше,
повторяешь для нужной половины.
```

**Плохо:**
```markdown
Бинарный поиск: алгоритм поиска в отсортированном
массиве со сложностью O(log n), основанный на
принципе "разделяй и властвуй".
```

### 3. Примеры

**Конкретные примеры с числами**

**Хорошо:**
```markdown
Пример: Факторизация 60
60 = 2 × 30
30 = 2 × 15
15 = 3 × 5
5 = 5 × 1

Результат: 60 = 2² × 3 × 5
```

### 4. Практичность

**Отвечает на "какую задачу решает"**

**Хорошо:**
```markdown
## Какую задачу решает

Факторизация позволяет:
- Найти все делители числа
- Понять почему число делится на другое
- Быстро вычислить НОД и НОК
```

### 5. Связи

**Ссылки на связанные заметки**

```markdown
## Связи

- [[02_trial_division]] - базовый алгоритм
- [[03_optimizations]] - почему до √n достаточно
- [[05_related_topics]] - НОД, НОК, делители
```

## Структура темы

### Папка темы

```
editorials/{topic}/
├── index.md              # Карта знаний
├── 01_concept_1.md       # Заметка 1
├── 02_concept_2.md       # Заметка 2
├── 03_concept_3.md       # Заметка 3
└── ...
```

### index.md - Карта знаний

**Содержит:**
- Обзор темы
- Карта концепций (граф связей)
- Навигация по заметкам
- Быстрый старт
- Типичные задачи

**Пример:** `editorials/examples/topic_analysis_example/index.md`

```markdown
# Тема - Карта знаний

## Обзор темы
[Краткое описание]

## Карта концепций
```
01 → 02 → 03
     ↓
     04 → 05
```

## Навигация
1. [[01_basics]] - Основы
2. [[02_algorithm]] - Алгоритм
...

## Быстрый старт
Новичок? Начни с [[01_basics]]
```

### Заметка - Атомарная концепция

**Структура:**

```markdown
# [Название концепции]

## Какую задачу решает
[Краткое описание проблемы]

## Суть
[Интуитивное объяснение]

## Пример
[Конкретный пример с разбором]

## Реализация
[Простой код]

## Сложность
[Временная и пространственная]

## Связи
- [[другая_заметка]] - описание связи
```

**Пример:** `editorials/examples/topic_analysis_example/01_prime_factorization.md`

## Создание материалов

### Через /coach (автоматически)

```
/coach → 1. ОБУЧЕНИЕ → выбрать тему
```

**Если материалов нет:**
```
Материалы по теме "geometry" не найдены.
Создаю структурированные материалы...

✅ Создано!
editorials/geometry/
├── index.md
├── 01_points_and_vectors.md
├── 02_distance.md
├── 03_cross_product.md
├── 04_line_intersection.md
└── 05_convex_hull.md
```

### Вручную

```
> Создай материалы по теме "suffix_array" в формате Zettelkasten
```

Claude:
- Создаёт папку `editorials/suffix_array/`
- Разбивает тему на атомарные концепции
- Создаёт index.md и заметки
- Добавляет связи между заметками

## Использование материалов

### Изучение новой темы

**1. Начни с index.md**
```
editorials/geometry/index.md
```

Получишь:
- Общее понимание темы
- Карту концепций (что за чем изучать)
- Рекомендации для начала

**2. Читай заметки по порядку**
```
01_basics.md → 02_algorithm.md → ...
```

**3. Следуй связям**

Если в заметке ссылка [[другая_тема]] - перейди и изучи.

### Справочник во время решения

**Быстрый поиск:**
```bash
# Найти заметку про cross product
ls editorials/geometry/*cross*

# Поиск по содержимому
grep -r "cross product" editorials/geometry/
```

**В Claude:**
```
> Что говорится про cross product в материалах по geometry?
```

Claude найдёт и покажет нужную заметку.

### Повторение перед контестом

**Прочитай index.md** - освежит все ключевые концепции.

**Перечитай слабые заметки** - где были пробелы.

## Дополнение материалов

### После решения задачи

Если узнал новое:
```
> Добавь в editorials/dp/ заметку про оптимизацию памяти
```

Claude:
- Создаёт новую заметку
- Добавляет связи с существующими
- Обновляет index.md

### После изучения внешних материалов

Если прочитал статью/tutorial:
```
> Прочитал про segment tree with lazy propagation.
  Добавь это в editorials/segment_tree/
```

Claude создаёт заметку на основе твоего понимания.

## Частые вопросы

### Сколько заметок в теме?

**Зависит от сложности темы:**
- Binary search: 3-5 заметок
- DP: 10-15 заметок (много подтем)
- Geometry: 15-20 заметок

**Оптимум:** 5-10 заметок на тему.

### Нужно ли читать все заметки?

**Для нового:** Да, по порядку.

**Для повторения:** Только слабые места.

**Для справки:** Только нужную заметку.

### Можно ли редактировать заметки?

**Да!** Материалы - живые документы.

После изучения:
- Добавь свои примеры
- Дополни объяснения
- Исправь неточности

### Как связаны материалы и библиотека?

**Материалы (editorials/)** - теория

**Библиотека (library/)** - код

**Связь:**
- В заметке есть секция "Реализация"
- Ссылка на файл в library/
- Или код прямо в заметке (если короткий)

### Можно ли создать материалы на английском?

**Да**, но рекомендуется на русском.

Claude может создать на любом языке, но для единства лучше выбрать один.
