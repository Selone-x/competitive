# Разбор 

Задача D. Жираф путешествует и кушает
Динамическое программирование на прямоугольном поле.
Динамика вперёд: из каждой клетки есть два возможных хода.
Динамика назад: в каждую клетку могли привести два хода.
Поскольку каждый ход увеличивает обе координаты, клетки можно перебирать в любом разум-
ном порядке.
Можно добавить параметр: чётность хода. Или заметить, что она однозначно определяется ко-
ординатами клетки.
