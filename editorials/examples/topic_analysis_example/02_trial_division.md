# Метод пробного деления (Trial Division)

## Какую задачу решает

Найти разложение числа `n` на простые множители, когда нужно **явно** получить все простые делители и их степени.

## Суть

**Идея:** Пробуем делить `n` на числа от `2` до `n`, пока `n > 1`.

Если число `d` делит `n`, продолжаем делить на `d`, пока делится (чтобы найти степень).

## Пример (пошагово)

**Разложим 360:**

```
n = 360, проверяем d = 2:
  360 % 2 == 0 ✓ → 360 / 2 = 180 (степень 2: a=1)
  180 % 2 == 0 ✓ → 180 / 2 = 90  (степень 2: a=2)
   90 % 2 == 0 ✓ → 90 / 2 = 45   (степень 2: a=3)
   45 % 2 != 0 ✗ → переходим к d = 3

n = 45, проверяем d = 3:
   45 % 3 == 0 ✓ → 45 / 3 = 15   (степень 3: a=1)
   15 % 3 == 0 ✓ → 15 / 3 = 5    (степень 3: a=2)
    5 % 3 != 0 ✗ → переходим к d = 4

n = 5, проверяем d = 4:
    5 % 4 != 0 ✗ → переходим к d = 5

n = 5, проверяем d = 5:
    5 % 5 == 0 ✓ → 5 / 5 = 1     (степень 5: a=1)

n = 1 → стоп

Результат: 2³ × 3² × 5¹
```

## Реализация

```cpp
map<long long, int> factorize(long long n) {
    map<long long, int> factors;

    // Перебираем делители от 2 до n
    for (long long d = 2; d * d <= n; d++) {
        while (n % d == 0) {
            factors[d]++;
            n /= d;
        }
    }

    // Если осталось n > 1, это простой делитель
    if (n > 1) {
        factors[n]++;
    }

    return factors;
}
```

**Пример использования:**

```cpp
auto factors = factorize(360);
// factors = {2: 3, 3: 2, 5: 1}

for (auto [prime, power] : factors) {
    cout << prime << "^" << power << " ";
}
// Вывод: 2^3 3^2 5^1
```

## Почему цикл до `d * d <= n`?

См. [[03_optimizations]] - это ключевая оптимизация.

## Сложность

- **Время:** O(√n) - перебираем делители до √n
- **Память:** O(log n) - количество простых делителей ≤ log₂(n)

## Когда использовать

- Нужно **явное** разложение на простые множители
- `n ≤ 10¹²` (можно обработать за ~1 секунду)
- Задачи на делимость, НОД, НОК, делители
