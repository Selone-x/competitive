# Связанные темы

## Какую задачу решает

Показывает связь факторизации с другими темами теории чисел и когда использовать альтернативные методы.

## НОД (Наибольший общий делитель)

### Связь с факторизацией

```
a = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ
b = p₁^b₁ × p₂^b₂ × ... × pₖ^bₖ

НОД(a, b) = p₁^min(a₁,b₁) × p₂^min(a₂,b₂) × ... × pₖ^min(aₖ,bₖ)
```

### Когда использовать факторизацию для НОД

**НЕ используйте** для вычисления НОД двух чисел - есть алгоритм Евклида (гораздо быстрее).

**Используйте**, когда:
- Нужно найти НОД с учётом ограничений (например, только по определённым простым)
- Анализируете свойства НОД через разложение

### Алгоритм Евклида (рекомендуется)

```cpp
long long gcd(long long a, long long b) {
    while (b) {
        a %= b;
        swap(a, b);
    }
    return a;
}

// Или встроенный
long long g = __gcd(a, b);
```

**Сложность:** O(log min(a, b)) vs O(√n) факторизации

## НОК (Наименьшее общее кратное)

### Формула через факторизацию

```
НОК(a, b) = p₁^max(a₁,b₁) × p₂^max(a₂,b₂) × ... × pₖ^max(aₖ,bₖ)
```

### Формула через НОД (рекомендуется)

```cpp
long long lcm(long long a, long long b) {
    return a / __gcd(a, b) * b;  // Делим сначала, чтобы избежать переполнения
}
```

**Важно:** `a * b / gcd(a, b)` может переполниться, поэтому делим сначала!

## Делители числа

### Все делители через факторизацию

```cpp
vector<long long> get_divisors(long long n) {
    auto factors = factorize(n);
    vector<long long> divisors = {1};

    for (auto [prime, power] : factors) {
        int sz = divisors.size();
        long long p_pow = 1;
        for (int i = 0; i < power; i++) {
            p_pow *= prime;
            for (int j = 0; j < sz; j++) {
                divisors.push_back(divisors[j] * p_pow);
            }
        }
    }

    sort(divisors.begin(), divisors.end());
    return divisors;
}
```

### Количество делителей (формула)

```
n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ

Количество делителей = (a₁ + 1) × (a₂ + 1) × ... × (aₖ + 1)
```

### Сумма делителей (формула)

```
Сумма делителей = [(p₁^(a₁+1) - 1) / (p₁ - 1)] × ... × [(pₖ^(aₖ+1) - 1) / (pₖ - 1)]
```

**Пример:**
```
n = 12 = 2² × 3

Сумма делителей = [(2³ - 1)/(2 - 1)] × [(3² - 1)/(3 - 1)]
                = [7/1] × [8/2]
                = 7 × 4
                = 28

Проверка: 1 + 2 + 3 + 4 + 6 + 12 = 28 ✓
```

## Простые числа

### Проверка простоты

**НЕ используйте факторизацию** для проверки простоты одного числа.

**Используйте:**

```cpp
bool is_prime(long long n) {
    if (n < 2) return false;
    if (n == 2) return true;
    if (n % 2 == 0) return false;

    for (long long d = 3; d * d <= n; d += 2) {
        if (n % d == 0) return false;
    }
    return true;
}
```

Для больших чисел: **тест Миллера-Рабина** (детерминированный для n < 2⁶⁴)

### Решето Эратосфена

Для нахождения всех простых до `N`:

```cpp
vector<bool> is_prime(N + 1, true);
is_prime[0] = is_prime[1] = false;

for (int i = 2; i * i <= N; i++) {
    if (is_prime[i]) {
        for (int j = i * i; j <= N; j += i) {
            is_prime[j] = false;
        }
    }
}
```

**Сложность:** O(N log log N)

## Модульная арифметика

### Малая теорема Ферма

```
Если p простое и gcd(a, p) = 1:
a^(p-1) ≡ 1 (mod p)

Следствие: a^(-1) ≡ a^(p-2) (mod p)
```

Используется для нахождения обратного по модулю.

### Китайская теорема об остатках

Если `m₁, m₂, ..., mₖ` взаимно просты, система:
```
x ≡ a₁ (mod m₁)
x ≡ a₂ (mod m₂)
...
x ≡ aₖ (mod mₖ)
```

имеет единственное решение по модулю `M = m₁ × m₂ × ... × mₖ`.

## Быстрая справка

| Задача | Метод | Сложность |
|--------|-------|-----------|
| НОД двух чисел | Алгоритм Евклида | O(log n) |
| НОК двух чисел | `a * b / gcd(a, b)` | O(log n) |
| Факторизация | Trial division | O(√n) |
| Все простые до N | Решето Эратосфена | O(N log log N) |
| Проверка простоты | Trial division / Miller-Rabin | O(√n) / O(k log² n) |
| Количество делителей | Через факторизацию | O(√n) |
