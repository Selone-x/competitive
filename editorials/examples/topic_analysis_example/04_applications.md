# Применение факторизации в задачах

## Какую задачу решает

Показывает **паттерны задач**, где нужна факторизация, и как её применять.

## Типичные паттерны задач

### Паттерн 1: "Сломать делимость"

**Признаки:**
- Дано: `p % q == 0`
- Найти: максимальное `x` (делитель `p`), где `x % q != 0`
- Ограничения: `p, q ≤ 10¹⁸`

**Решение:**
1. Факторизовать `q` на простые
2. Для каждого простого `d` из `q`:
   - Делить `p` на `d`, пока `p % q == 0`
   - Запомнить максимальный результат

**Пример (задача Codeforces 1444A):**

```
p = 100, q = 10

Факторизация q = 10 = 2 × 5

Пробуем d = 2:
  100 % 10 == 0 ✓ → 100 / 2 = 50
   50 % 10 == 0 ✓ → 50 / 2 = 25
   25 % 10 != 0 ✗ → ans = 25

Пробуем d = 5:
  100 % 10 == 0 ✓ → 100 / 5 = 20
   20 % 10 == 0 ✓ → 20 / 5 = 4
    4 % 10 != 0 ✗ → ans = max(25, 4) = 25

Ответ: 25
```

**Код:**

```cpp
long long solve(long long p, long long q) {
    if (p % q != 0) return p;

    long long ans = 0;

    // Факторизуем q
    for (long long d = 2; d * d <= q; d++) {
        if (q % d == 0) {
            long long temp = p;
            while (temp % q == 0) {
                temp /= d;
            }
            ans = max(ans, temp);
        }
    }

    // Проверяем q как простое (или оставшийся делитель > √q)
    long long temp = p;
    while (temp % q == 0) {
        temp /= q;
    }
    ans = max(ans, temp);

    return ans;
}
```

### Паттерн 2: Количество делителей

**Признаки:**
- Найти количество делителей числа `n`
- Или сумму делителей

**Формула:**
```
n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ

Количество делителей = (a₁ + 1) × (a₂ + 1) × ... × (aₖ + 1)
```

**Пример:**
```
n = 360 = 2³ × 3² × 5

Количество делителей = (3 + 1) × (2 + 1) × (1 + 1) = 4 × 3 × 2 = 24
```

**Код:**

```cpp
int count_divisors(long long n) {
    auto factors = factorize(n);
    int result = 1;
    for (auto [prime, power] : factors) {
        result *= (power + 1);
    }
    return result;
}
```

### Паттерн 3: НОД и НОК через факторизацию

**Применение:** Когда нужно найти НОД/НОК нескольких чисел или вычислить их свойства.

**Формулы:**
```
НОД(a, b) = произведение p^min(степень в a, степень в b)
НОК(a, b) = произведение p^max(степень в a, степень в b)
```

**Пример:**
```
a = 360 = 2³ × 3² × 5
b = 100 = 2² × 5²

НОД = 2^min(3,2) × 3^min(2,0) × 5^min(1,2) = 2² × 5 = 20
НОК = 2^max(3,2) × 3^max(2,0) × 5^max(1,2) = 2³ × 3² × 5² = 1800
```

### Паттерн 4: Проверка, является ли число степенью

**Признаки:**
- Проверить, является ли `n` степенью какого-то числа
- Найти максимальное `k`, что `n = m^k`

**Решение:**
```
n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ

n является степенью ⟺ НОД(a₁, a₂, ..., aₖ) > 1
```

**Код:**

```cpp
bool is_perfect_power(long long n) {
    auto factors = factorize(n);
    if (factors.empty()) return false;

    int g = 0;
    for (auto [prime, power] : factors) {
        g = __gcd(g, power);
    }

    return g > 1;
}
```

## Когда НЕ нужна факторизация

- НОД двух чисел → используйте алгоритм Евклида (быстрее)
- Проверка простоты → используйте тест Миллера-Рабина
- Поиск делителей в диапазоне → решето Эратосфена

## Ограничения

**Факторизация работает при:**
- `n ≤ 10¹²` - за O(√n) = O(10⁶) (1 секунда)
- Для больших чисел нужны продвинутые методы (ро-алгоритм Полларда)
