## Что это?

Это рабочая среда для олимпиадного программирования, которая использует Claude Code CLI для:

- 🎯 **Разбора неполучившихся задач** - фокус на ошибках в мышлении, а не только коде
- 📚 **Изучения новых тем** - структурированные заметки в формате Zettelkasten
- 🔧 **Сбора библиотеки** - готовые реализации алгоритмов для быстрого копирования
- 💡 **Интерактивного обучения** - диалог с проверкой понимания

**Ключевая фишка:** Claude не просто даёт решение, а помогает понять *почему* задача не получилась и *как* мыслить в следующий раз.

## Быстрый старт

### Установка

1. Установите [Claude Code CLI](https://claude.ai/download)
2. Клонируйте этот репозиторий:
   ```bash
   git clone <your-repo-url>
   cd competitive
   ```
3. Запустите Claude Code в этой директории:
   ```bash
   claude
   ```

### Первое использование

**Вариант 1: Разобрать задачу**

1. Откройте `competitive_task.md`
2. Вставьте ссылку на задачу
3. Вызовите команду:
   ```
   /solve_problem
   ```

**Вариант 2: Изучить тему**

```
/topic_analysis binary_search
```

Claude создаст структурированные заметки и код в `library/`.

## Кастомные команды

### `/solve_problem` - Разбор задач

**Назначение:** Помощь в решении задачи или объяснение готового разбора.

#### Как использовать

1. Откройте `competitive_task.md`
2. Добавьте ссылку на задачу:
   ```markdown
   # Ссылка на задачу
   https://codeforces.com/contest/123/problem/D

   ---

   # Разбор

   ```
3. Вызовите `/solve_problem`

#### Два режима работы

**Режим 1: Есть разбор** (когда после `# Разбор` есть текст)
- Claude объяснит решение понятным языком
- Выделит ключевые идеи
- Покажет паттерны применения

**Режим 2: Нет разбора** (когда после `# Разбор` пусто)
- Диалог: задавайте вопросы, Claude направляет мышление
- НЕ даёт готовое решение сразу
- Запоминает весь ход обсуждения
- Проверяет усвоение через вопросы
- Создаёт итоговый разбор

#### Что на выходе

Файл `editorials/[название_задачи].md` с разбором:
- ✅ Что было понято правильно
- ❌ Пропущенные шаги и ошибки
- 💡 Правильное решение с ключевой мыслью
- 🎯 Признаки задач этого типа
- 📚 Темы для изучения

**Пример:** См. `editorials/examples/task_editorial_example.md`

---

### `/topic_analysis` - Изучение тем

**Назначение:** Глубокое изучение любой темы в формате Zettelkasten (атомарные заметки со связями).

#### Как использовать

```
/topic_analysis [название темы]
```

**Примеры:**
```
/topic_analysis binary_search
/topic_analysis segment_tree
/topic_analysis dynamic_programming
```

#### Что происходит

1. **Разбивает тему** на атомарные концепции
2. **Создаёт заметки** в формате Zettelkasten:
   - Каждая заметка = одна идея
   - С примерами и кодом
   - Связи между заметками
3. **Создаёт `index.md`** с картой знаний
4. **Проверяет усвоение** через вопросы
5. **Добавляет в библиотеку** готовый код

#### Что на выходе

- Папка `editorials/[тема]/` с заметками
- Файлы `library/cpp/[тема].cpp` и `library/py/[тема].py`

**Пример:** См. `editorials/examples/topic_analysis_example/`

### Формат разбора темы (Zettelkasten)

#### Структура папки

```
topic_name/
├── index.md              # Карта знаний с навигацией
├── 01_concept_1.md       # Атомарная заметка 1
├── 02_concept_2.md       # Атомарная заметка 2
├── 03_concept_3.md       # Атомарная заметка 3
└── ...
```

#### Формат каждой заметки

```markdown
# [Название концепции]

## Какую задачу решает
[Краткое описание проблемы]

## Суть
[Интуитивное объяснение]

## Пример
[Конкретный пример с пошаговым разбором]

## Реализация
[Простой код]

## Сложность
[Временная и пространственная сложность]

## Связи
- [[другая_заметка]] - описание связи
```

#### Принципы Zettelkasten

- **Краткость** - каждая заметка = одна атомарная идея
- **Интуитивность** - объяснение на простом языке
- **Примеры** - конкретные примеры с числами
- **Практичность** - отвечает на "какую задачу решает"
- **Связи** - ссылки на связанные заметки

## Работа с библиотекой

### Структура файлов

Каждый файл в `library/` имеет единый формат для быстрого копирования:

```python
# [Название алгоритма/структуры]
# Ключевые слова: keyword1, keyword2, keyword3
# Сложность: O(...)
# Описание: краткое описание

# ============ НАЧАЛО КОПИРУЕМОГО БЛОКА ============
# Чистый код БЕЗ комментариев - готов для вставки в решение

def algorithm(n):
    result = 0
    for i in range(n):
        result += i
    return result

# ============ КОНЕЦ КОПИРУЕМОГО БЛОКА ============

# ============ РЕАЛИЗАЦИЯ С КОММЕНТАРИЯМИ ============
# Та же реализация, но с подробными комментариями

def algorithm(n):
    """Вычисляет сумму чисел от 0 до n-1"""
    result = 0  # Накопитель суммы
    for i in range(n):
        result += i
    return result

# ============ КОНЕЦ КОММЕНТИРОВАННОЙ ВЕРСИИ ============

# Примеры использования:
def example():
    print(algorithm(10))  # Вывод: 45
```

### Как использовать библиотеку

1. **Поиск:** Используйте ключевые слова в начале файла
   - Grep по `library/`: `grep -r "binary search" library/`
   - Поиск в IDE по ключевым словам

2. **Копирование:**
   - Откройте нужный файл
   - Скопируйте блок между `НАЧАЛО/КОНЕЦ КОПИРУЕМОГО БЛОКА`
   - Вставьте в `solution/cpp/task.cpp` или `solution/py/main.py`

3. **Изучение:**
   - Смотрите комментированную версию ниже
   - Смотрите примеры использования

### Примеры

- **C++:** `library/cpp/prime_factorization.cpp`
- **Python:** `library/py/prime_factorization.py`

## 💡 Советы

### Для максимальной эффективности

1. **После каждой задачи** создавайте разбор, даже если решили сами
   - Фиксируйте, какая идея была ключевой
   - Какие признаки задачи заметили

2. **Регулярно пополняйте библиотеку**
   - После изучения темы → код в `library/`
   - Используйте `/topic_analysis` для структурированного изучения

3. **Переиспользуйте код**
   - Все блоки в `library/` готовы к копированию
   - Не пишите одно и то же дважды

4. **Проверяйте понимание**
   - Claude задаёт вопросы не просто так
   - Если не можете ответить → тема не усвоена

### Интеграция в команду

1. **Общая библиотека** - все добавляют в `library/`
2. **Обмен разборами** - делитесь файлами из `editorials/`
3. **Код-ревью** - проверяйте решения друг друга
4. **Обсуждение ошибок** - раздел "Пропущенный шаг" особенно полезен

## 🎯 Философия системы

Эта система основана на идее, что:

> **Олимпиадное программирование - это не про знание алгоритмов, а про умение мыслить.**

Поэтому:

- ❌ Не фокусируемся только на коде
- ✅ Анализируем **процесс мышления**
- ✅ Выявляем **ошибки в логике**
- ✅ Формулируем **критические вопросы**
- ✅ Находим **паттерны** задач

Claude Code помогает не просто решать задачи, а **учиться решать задачи**.
