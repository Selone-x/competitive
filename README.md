# 🏆 Claude Coach - Персональный тренер по спортивному программированию

Система персонального коучинга для competitive programming на базе Claude Code CLI.

**Не просто решение задач, а системное обучение с фокусом на процессе мышления.**

## 🚀 Быстрый старт

```bash
# 1. Установи Claude Code CLI
# Скачай с https://claude.ai/download

# 2. Клонируй репозиторий
git clone <your-repo-url>
cd competitive

# 3. Запусти Claude Code
claude

# 4. Инициализируй тренера
/coach
```

При первом запуске тренер автоматически:
- Проанализирует твой профиль на Codeforces
- Оценит знания по 10 темам через quiz
- Создаст персональный план тренировок

## ✨ Ключевые возможности

### 🎓 Персональный тренер
- Анализ профиля Codeforces через API
- Оценка знаний по 10 основным темам (quiz)
- Персональный план тренировок под твой уровень
- Отслеживание прогресса (confidence 1-10 по каждой теме)

### 📚 Режимы работы
- **Обучение** - изучение слабых тем с материалами и quiz
- **Практика** - решение задач с консультацией (не даёт решение, а направляет)
- **Drill** - тренировка мышечной памяти (набивание кода по памяти)
- **Contest** - анализ участия в контестах (solo/team)

### 🧠 Фокус на мышлении
- Разборы задач с акцентом на **процесс мышления**, а не только код
- Выявление **ошибок в логике**: "почему не додумался?"
- Формулировка **критических вопросов**, которые нужно было задать
- Поиск **паттернов распознавания** задач

### 📖 Структурированные материалы
- **Zettelkasten** - атомарные заметки по темам со связями
- **Библиотека алгоритмов** - готовый код для копирования в контесте
- **Editorials** - разборы задач в едином формате

## 💡 Философия

> **Олимпиадное программирование - это не про знание алгоритмов, а про умение мыслить.**

Claude Coach помогает не просто решать задачи, а **учиться решать задачи**:
- ❌ Не даёт готовое решение проактивно
- ✅ Консультирует когда спрашиваешь
- ✅ Анализирует твой процесс мышления
- ✅ Выявляет слабые места и помогает их подтянуть

## 📖 Примеры использования

### Первая тренировка

```
/coach
→ Выбери "1. 📚 ОБУЧЕНИЕ"
→ Выбери слабую тему
→ Пройди quiz
→ Решай практическую задачу
```

### Решение задачи

```
/coach
→ Выбери "2. 💻 ПРАКТИКА"
→ Получи рекомендацию или введи ссылку
→ Решай с консультацией тренера
→ После AC - получи разбор
```

### Анализ контеста

```
# 1. Вставь ссылку в solution/CONTEST.md
# 2. Запусти /coach contest
# 3. Ответь на вопросы
# 4. Изучи анализ и рекомендации
```
