## Что это?

Это рабочая среда для олимпиадного программирования, которая использует Claude Code CLI для:

- 🎓 **Персонального коучинга** - анализ профиля CF, персональный план тренировок, отслеживание прогресса
- 🎯 **Разбора неполучившихся задач** - фокус на ошибках в мышлении, а не только коде
- 📚 **Изучения новых тем** - структурированные заметки в формате Zettelkasten
- 🔧 **Сбора библиотеки** - готовые реализации алгоритмов для быстрого копирования
- 🔨 **Drill (набивашки)** - тренировка мышечной памяти: набивание кода из библиотеки по памяти с семантической проверкой
- 💡 **Интерактивного обучения** - диалог с проверкой понимания

**Ключевая фишка:** Claude не просто даёт решение, а помогает понять *почему* задача не получилась и *как* мыслить в следующий раз. Персональный тренер анализирует твои слабые места и составляет план для их устранения.

## Быстрый старт

### Установка

1. Установите [Claude Code CLI](https://claude.ai/download)
2. Клонируйте этот репозиторий:
   ```bash
   git clone <your-repo-url>
   cd competitive
   ```
3. Запустите Claude Code в этой директории:
   ```bash
   claude
   ```

### Первое использование

**Рекомендуется: Начать с персонального тренера**

```
/coach
```

При первом запуске тренер автоматически:
- Проанализирует твой профиль на Codeforces
- Оценит твои знания по основным темам
- Создаст персональный план тренировок
- Далее будет отслеживать прогресс и рекомендовать задачи

**Альтернативно: Работать без тренера**

Разобрать конкретную задачу или изучить тему (см. секцию "Рабочий процесс" ниже).

## Персональный тренер 🎓

Система персонального коучинга с анализом слабых мест, персональным планом тренировок и отслеживанием прогресса.

### Первый запуск

```
/coach
```

При первом запуске (когда профиля нет) тренер автоматически запустит процесс инициализации и спросит:
1. Твой никнейм на Codeforces (для анализа статистики)
2. Адаптивный quiz по основным темам (Binary Search, DP, Graphs, и т.д.) — 2–3 вопроса на тему, уровень определяется автоматически
3. Целевой рейтинг и предпочтения тренировок

На основе этих данных будет создан профиль в `coach/core.json` (основные данные) и `coach/stats.json` (статистика и история).

**Переинициализация профиля:**
```
/coach init
```
Создаст новый профиль с нуля (старый будет перезаписан).

### Режимы работы

```
/coach
```

После вызова команды выбираешь режим:

#### 📚 Режим обучения

**Что делает:**
- Предлагает самую слабую тему на основе твоего профиля
- Если изучал эту тему раньше — начинает с подтопиков, которые не были усвоены
- Создаёт или использует существующие материалы (формат Zettelkasten)
- Проводит quiz для проверки понимания (5 вопросов)
  - Каждый вопрос привязан к подтопику (definition, use_cases, implementation, pattern_matching, edge_cases)
  - Если есть слабые подтопики с прошлой сессии — вопросы на них идут первыми
- Даёт практическую задачу на тему
- Показывает готовый код из библиотеки
- Обновляет твой уровень (confidence) по теме

**Результат:**
- Повышение confidence по теме
- Записывается **что усвоил** и **что не усвоил** (по подтопикам)
- Новые материалы в `editorials/{topic}/` (если их не было)
- Код в `library/{lang}/{topic}/` для будущего использования
- Запись в историю сессий

**Когда использовать:**
- Когда хочешь подтянуть слабую тему
- Когда изучаешь что-то новое
- Когда нужно освежить знания

#### 🔨 Режим drill (набивашки)

**Что делает:**
- Показывает метаданные алгоритма из `library/` (имя, сложность, описание, сигнатуры функций)
- Пользователь набивает код по памяти в `solution/cpp/task.cpp` (или `solution/py/main.py`)
- По команде "готово" Claude читает файл и семантически сравнивает с эталоном (КОПИРУЕМЫЙ БЛОК)
- Даёт обратную связь: что верно, что пропущено, какие ошибки
- Показывает эталон после проверки

**Результат:**
- Тренировка мышечной памяти — быстрее набиваешь на контесте
- Запись в `drill_history` (accuracy_score, пропущенные части)
- Drill **не влияет на confidence** — это тренировка, не изучение

**Когда использовать:**
- Когда знаешь алгоритм теоретически, но набиваешь медленно
- Перед контестом — разогреть руки
- Регулярно — для поддержания мышечной памяти

#### 💻 Режим практики

**Что делает:**
- Рекомендует задачу на основе:
  - Твоих слабых тем
  - Текущего плана тренировок
  - Или принимает твою ссылку на задачу
- Ведёт диалог в режиме консультанта: обсуждает когда пользователь спрашивает, НЕ даёт готовое решение и не наводит на решение проактивно
- Запоминает весь ход обсуждения (мысли, прорывы, ошибки)
- После решения создаёт краткий разбор
- Предлагает создать детальный editorial (опционально)

**Результат:**
- Решённая задача с твоим пониманием
- Краткий разбор (что получилось, что нет, ключевая идея)
- Обновление confidence по практикуемым темам
- Статистика (attempts, solved) в профиле
- Опционально: детальный editorial в `editorials/`

**Когда использовать:**
- Когда хочешь решить задачу с поддержкой
- Когда застрял на задаче
- Когда нужна рекомендация задачи на слабую тему

#### 📊 Режим анализа контеста

**Что делает:**
- Загружает результаты твоего участия в контесте через Codeforces API
- Поддерживает solo (индивидуальные) и team (командные) контесты
- Показывает таблицу с попытками, временем и вердиктами по каждой задаче
- Задаёт вопросы о нерешённых задачах (почему не получилось)
- Анализирует стратегию решения (порядок задач, распределение времени)
- Для team: анализирует вклад участников, эффективность команды, координацию
- Выявляет паттерны ошибок и слабые темы
- Сравнивает с профилем (подтверждённые vs новые слабости)
- Создаёт детальный разбор контеста

**Результат:**
- Файл анализа в `editorials/{contest_id}_analysis.md` (solo) или `editorials/{contest_id}_team_analysis.md` (team)
- Запись в `contest_history` или `team_contest_history` в профиле
- Конкретные рекомендации что подтянуть
- Понимание своих стратегических ошибок
- Для team: рекомендации по координации и распределению ролей

**Когда использовать:**
- После каждого контеста для извлечения уроков
- Для выявления повторяющихся ошибок
- Для улучшения стратегии участия в контестах
- После командных тренировок для анализа взаимодействия

**Как использовать:**
1. Вставь ссылку на контест в `solution/CONTEST.md` (секция "Ссылка на контест")
2. Укажи тип контеста: `solo` или `team`
3. Если team — добавь handles участников
4. Запусти `/coach contest`
5. Ответь на вопросы о нерешённых задачах и стратегии
6. Изучи сгенерированный анализ

### Дополнительные команды

Все команды также доступны через интерактивное меню `/coach` (пункты 4-8):

```bash
/coach              # Интерактивное меню с 8 режимами (НОВОЕ!)
/coach stats        # Статистика прогресса (рейтинг, confidence, решённых задач)
/coach plan         # Показать текущий план тренировок
/coach sync         # Синхронизация с Codeforces (обновить статистику)
/coach drill        # Набить код из библиотеки по памяти (автовыбор темы)
/coach drill topic  # Набить конкретную тему (например: /coach drill prime_factorization)
/coach contest      # Проанализировать результаты контеста (ссылка в solution/WORKSPACE.md)

/coach reset topic  # Сбросить прогресс по конкретной теме
```

**Примечание:** Используй интерактивное меню `/coach` для удобства, или прямые команды для быстрого доступа.

### Как это работает

**Анализ CF профиля:**
- Скрипт `codeforces_api.py` получает статистику через CF API
- Анализирует частые и редкие темы
- Сравнивает с самооценкой для выявления слабых мест

**Обновление confidence:**
- После quiz в режиме обучения: +1-2 к confidence
- После решения задачи в режиме практики: +1 к confidence
- Постепенный рост - тема становится сильной не за одну сессию

**План тренировок:**
- Автоматически определяется фаза (fundamentals/intermediate/advanced)
- Приоритизируются темы с низким confidence
- Учитываются твои предпочтения (сбалансированный/фокус/челлендж)

**Интеграция с существующими командами:**
- Режим обучения использует внутри логику создания материалов (Zettelkasten)
- Режим практики использует внутри логику разбора задач
- Всё автоматически - не нужно вызывать отдельные команды

## Форматы

### Устаревшие команды

Команды `/solve_problem` и `/topic_analysis` теперь интегрированы в `/coach`. Используй:
- `/coach` → режим практики (вместо `/solve_problem`)

### Формат разбора темы (Zettelkasten)

#### Структура папки

```
topic_name/
├── index.md              # Карта знаний с навигацией
├── 01_concept_1.md       # Атомарная заметка 1
├── 02_concept_2.md       # Атомарная заметка 2
├── 03_concept_3.md       # Атомарная заметка 3
└── ...
```

#### Формат каждой заметки

```markdown
# [Название концепции]

## Какую задачу решает
[Краткое описание проблемы]

## Суть
[Интуитивное объяснение]

## Пример
[Конкретный пример с пошаговым разбором]

## Реализация
[Простой код]

## Сложность
[Временная и пространственная сложность]

## Связи
- [[другая_заметка]] - описание связи
```

#### Принципы Zettelkasten

- **Краткость** - каждая заметка = одна атомарная идея
- **Интуитивность** - объяснение на простом языке
- **Примеры** - конкретные примеры с числами
- **Практичность** - отвечает на "какую задачу решает"
- **Связи** - ссылки на связанные заметки

## Работа с библиотекой

### Структура файлов

Каждый файл в `library/` имеет единый формат для быстрого копирования:

```python
# [Название алгоритма/структуры]
# Ключевые слова: keyword1, keyword2, keyword3
# Сложность: O(...)
# Описание: краткое описание

# ============ НАЧАЛО КОПИРУЕМОГО БЛОКА ============
# Чистый код БЕЗ комментариев - готов для вставки в решение

def algorithm(n):
    result = 0
    for i in range(n):
        result += i
    return result

# ============ КОНЕЦ КОПИРУЕМОГО БЛОКА ============

# ============ РЕАЛИЗАЦИЯ С КОММЕНТАРИЯМИ ============
# Та же реализация, но с подробными комментариями

def algorithm(n):
    """Вычисляет сумму чисел от 0 до n-1"""
    result = 0  # Накопитель суммы
    for i in range(n):
        result += i
    return result

# ============ КОНЕЦ КОММЕНТИРОВАННОЙ ВЕРСИИ ============

# Примеры использования:
def example():
    print(algorithm(10))  # Вывод: 45
```

### Как использовать библиотеку

1. **Поиск:** Используйте ключевые слова в начале файла
   - Grep по `library/`: `grep -r "binary search" library/`
   - Поиск в IDE по ключевым словам

2. **Копирование:**
   - Откройте нужный файл
   - Скопируйте блок между `НАЧАЛО/КОНЕЦ КОПИРУЕМОГО БЛОКА`
   - Вставьте в `solution/cpp/task.cpp` или `solution/py/main.py`

3. **Изучение:**
   - Смотрите комментированную версию ниже
   - Смотрите примеры использования

### Примеры

- **C++:** `library/cpp/prime_factorization.cpp`
- **Python:** `library/py/prime_factorization.py`

## 💡 Советы

### Для максимальной эффективности

1. **После каждой задачи** создавайте разбор, даже если решили сами
   - Фиксируйте, какая идея была ключевой
   - Какие признаки задачи заметили

2. **Регулярно пополняйте библиотеку**
   - После изучения темы → код в `library/`
   - Режим обучения в `/coach` автоматически создаёт материалы и код

3. **Переиспользуйте код**
   - Все блоки в `library/` готовы к копированию
   - Не пишите одно и то же дважды

4. **Проверяйте понимание**
   - Claude задаёт вопросы не просто так
   - Если не можете ответить → тема не усвоена

### Интеграция в команду

1. **Общая библиотека** - все добавляют в `library/`
2. **Обмен разборами** - делитесь файлами из `editorials/`
3. **Код-ревью** - проверяйте решения друг друга
4. **Обсуждение ошибок** - раздел "Пропущенный шаг" особенно полезен

- ✅ Формулируем **критические вопросы**
- ✅ Находим **паттерны** задач

Claude Code помогает не просто решать задачи, а **учиться решать задачи**.
